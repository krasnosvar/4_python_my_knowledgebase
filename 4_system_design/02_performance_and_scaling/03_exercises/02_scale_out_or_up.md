# Упражнение 02: масштабировать вширь или ввысь

## Сценарий

Сервис обработки видео состоит из двух компонентов:

- **API-сервис** (FastAPI) — принимает запросы на загрузку видео, отдаёт статус обработки, полностью stateless (никакого состояния между запросами в памяти процесса). Сейчас 2 инстанса за балансировщиком, утилизация CPU ~30% на каждом при текущей нагрузке.
- **Транскодер** — CPU-bound процесс, который берёт загруженное видео и перекодирует его в несколько разрешений. Сейчас один мощный сервер с 32 ядрами, утилизация CPU ~85% в часы пик, обрабатывает видео строго по одному за раз в порядке очереди (одна очередь FIFO на входе).

Бизнес хочет вдвое увеличить пропускную способность обработки видео в течение следующего квартала.
