# Упражнение 04: расставить уровни кэша (хардкор)

## Сценарий

Проектируете кэширование для сервиса онлайн-курсов со следующими типами контента:

- Страница описания курса (название, программа, преподаватель, отзывы) — одинакова для всех пользователей, меняется редко (раз в дни/недели).
- Видео уроков — большие статичные файлы, не меняются после публикации.
- Личный прогресс пользователя по курсу (какие уроки просмотрены, результаты тестов) — уникален для каждого пользователя, меняется при каждом действии.
- Список «рекомендованные курсы для вас» на главной странице — персонализирован, но пересчитывается тяжёлым batch-процессом раз в 6 часов, а не в реальном времени.
- Текущее количество свободных мест на курс с ограниченным набором — общее для всех, но должно быть точным в момент оплаты (не должно допускать перепродажу мест).
