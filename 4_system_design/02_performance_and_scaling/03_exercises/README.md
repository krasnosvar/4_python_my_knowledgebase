# Упражнения: производительность и масштабирование (Performance and Scaling)

Каждая задача — сценарий системного дизайна: описание ситуации и вопросы для
письменного разбора с обоснованием компромиссов. В `04_exercises_answers/`
приведено разобранное рассуждение для самопроверки.

## Список задач (от простого к сложному)

1. `01_find_the_bottleneck.md` — по метрикам путей запроса найти реальное узкое
   место и отличить его от «звена, которое просто выглядит медленным».
2. `02_scale_out_or_up.md` — выбрать между вертикальным и горизонтальным
   масштабированием для двух разных компонентов одной Python-системы с учётом
   GIL.
3. `03_shard_the_dataset.md` — выбрать ключ шардирования для конкретного
   датасета и оценить последствия для типичных запросов.
4. `04_cache_layers_design.md` — расставить уровни кэширования (CDN/L1/L2) под
   конкретный продукт с разной степенью персонализации контента (хардкор).
