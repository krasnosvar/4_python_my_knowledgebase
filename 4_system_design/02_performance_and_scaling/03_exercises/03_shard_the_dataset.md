# Упражнение 03: выбрать ключ шардирования

## Сценарий

Сервис бронирования такси хранит таблицу `trips` (поездки): `trip_id`,
`rider_id` (пассажир), `driver_id` (водитель), `city_id` (город), `started_at`,
`status`, `fare_amount`. Таблица растёт на 50 млн строк в месяц и уже не
помещается на одном узле БД с приемлемой производительностью записи. Типичные
запросы к системе, по частоте:

1. «История поездок конкретного пассажира» (очень частый, личный кабинет).
2. «Все активные поездки в конкретном городе прямо сейчас» (частый, для
   диспетчеризации и мониторинга).
3. «Суммарная выручка по всем городам за прошлый месяц» (редкий, ежемесячная
   аналитика/отчётность).
