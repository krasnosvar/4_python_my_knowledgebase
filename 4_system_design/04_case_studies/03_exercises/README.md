# Упражнения: разбор кейсов (Case Studies)

Каждая задача — продолжение одного из двух разобранных кейсов
(`01_money_transfers_in_python.md`, `02_image_gallery_in_python.md`): системе
задают новое требование или резкий рост нагрузки, и нужно письменно
спроектировать, как решение эволюционирует. В `04_exercises_answers/`
приведено разобранное рассуждение для самопроверки.

## Список задач

1. `01_transfer_growth.md` — система переводов из
   `01_money_transfers_in_python.md` получает новое требование и кратный рост
   нагрузки; спроектировать эволюцию решения.
2. `02_gallery_growth.md` — система галереи из `02_image_gallery_in_python.md`
   получает новое требование (приватные альбомы) и кратный рост нагрузки;
   спроектировать эволюцию решения (хардкор).
