# Упражнения: case studies

Каждая задача — продолжение одного из двух разобранных кейсов (`01_money_transfers.md`, `02_image_gallery.md`): системе задают новое требование или резкий рост нагрузки, и нужно письменно спроектировать, как решение эволюционирует. В `04_exercises_answers/` — разобранное рассуждение, а не единственно верный шаблонный ответ.

## Список задач

1. `01_transfer_growth.md` — система переводов из `01_money_transfers.md` получает новое требование и кратный рост нагрузки; спроектировать эволюцию решения.
2. `02_gallery_growth.md` — система галереи из `02_image_gallery.md` получает новое требование (приватные альбомы) и кратный рост нагрузки; спроектировать эволюцию решения (хардкор).
