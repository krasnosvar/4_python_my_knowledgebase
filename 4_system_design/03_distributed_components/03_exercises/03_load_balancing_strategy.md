# Упражнение 03: выбрать алгоритм балансировки

## Сценарий

Три независимых сервиса за разными балансировщиками:

1. `thumbnail-service` — генерирует превью изображений; запросы почти одинаковы
   по времени обработки (все изображения примерно одного размера, обработка
   занимает 50–80 мс).
2. `reports-service` — генерирует отчёты; часть запросов — простые отчёты (200
   мс), часть — тяжёлые сводные за год (10–15 секунд), заранее по запросу
   неизвестно, какой именно окажется.
3. `websocket-gateway` — держит постоянные WebSocket-соединения с клиентами
   чата; каждое соединение живёт часами, и gateway хранит в памяти локальный
   список активных соединений своего инстанса для быстрой доставки сообщений.
