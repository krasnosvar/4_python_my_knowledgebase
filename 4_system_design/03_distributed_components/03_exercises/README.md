# Упражнения: distributed components

Каждая задача — сценарий системного дизайна: описание ситуации и вопросы для письменного разбора с обоснованием компромиссов. В `04_exercises_answers/` — разобранное рассуждение, а не единственно верный шаблонный ответ.

## Список задач (от простого к сложному)

1. `01_design_the_gateway.md` — определить, что должен и не должен брать на себя API Gateway для конкретной системы.
2. `02_pick_the_database.md` — подобрать БД (и обосновать полиглот-персистентность или отказ от неё) под несколько сервисов с разным профилем нагрузки.
3. `03_load_balancing_strategy.md` — выбрать алгоритм балансировки под конкретный профиль трафика.
4. `04_service_discovery_failure.md` — разобрать отказ в системе через призму health checks и service discovery (хардкор).
