# Упражнения: компоненты распределённых систем (Distributed Components)

Каждая задача — сценарий системного дизайна: описание ситуации и вопросы для
письменного разбора с обоснованием компромиссов. В `04_exercises_answers/`
приведено разобранное рассуждение для самопроверки.

## Список задач (от простого к сложному)

1. `01_design_the_gateway.md` — определить, что должен и не должен брать на
   себя API Gateway и где место BFF для конкретной системы.
2. `02_pick_the_database.md` — подобрать БД (и обосновать
   полиглот-персистентность) под несколько сервисов с разным профилем нагрузки.
3. `03_load_balancing_strategy.md` — выбрать алгоритм балансировки и схему
   хранения состояния под конкретный профиль трафика.
4. `04_service_discovery_failure.md` — разобрать продакшн-инцидент через призму
   health checks (Liveness vs Readiness), таймаутов и ретраев (хардкор).
