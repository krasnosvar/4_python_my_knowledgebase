# Упражнение 02: подобрать БД под сервисы

## Сценарий

Проектируете систему для площадки объявлений (аналог классифайда). Выделены
сервисы:

- `listings-service` — карточки объявлений: заголовок, цена, категория,
  продавец, статус; много изменений полей, нужны транзакции при смене статуса
  (например, «зарезервировано» → «продано»).
- `search-service` — полнотекстовый и фасетный поиск по объявлениям (фильтры по
  цене, категории, региону, свободный текст в заголовке/описании).
- `chat-service` — переписка между покупателем и продавцом по конкретному
  объявлению: последовательность сообщений, растёт непрерывно, читается почти
  всегда только «последние сообщения этого диалога».
- `pricing-analytics-service` — раз в сутки считает агрегаты: средняя цена по
  категориям и регионам за исторический период, для внутренней аналитики и
  отчётов.
- `session-service` — хранит активные сессии пользователей (`токен → user_id`,
  TTL сессии).
