# Упражнения: архитектурные стили (Architecture Styles)

Каждая задача — это сценарий системного дизайна: описание ситуации и вопросы,
на которые нужно ответить письменно, обосновав архитектурные компромиссы. В
`04_exercises_answers/` приведено разобранное рассуждение, с которым стоит
сверить свою логику.

## Список задач (от простого к сложному)

1. `01_startup_monolith_or_microservices.md` — стартап на 4 Python-разработчика
   выбирает архитектуру для нового продукта: модульный монолит или
   микросервисы, и почему.
2. `02_spot_the_distributed_monolith.md` — по описанию существующей системы
   определить признаки распределённого монолита и предложить план лечения.
3. `03_migration_plan.md` — составить план инкрементальной миграции
   Django-монолита на сервисы через Strangler Fig, включая порядок выноса
   модулей.
4. `04_team_topology_fit.md` — подобрать архитектуру под заданную структуру
   команд и обосновать выбор через призму закона Конвея.
