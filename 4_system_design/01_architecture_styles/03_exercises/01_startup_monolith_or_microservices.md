# Упражнение 01: стартап выбирает архитектуру

## Сценарий

Команда из 4 разработчиков (Python/Django) начинает новый продукт — платформу
бронирования переговорных комнат для офисов. Продукт ещё не запущен,
product-market fit не найден, требования меняются каждую неделю по итогам
общения с первыми клиентами. Ожидаемая нагрузка на старте — не больше пары
сотен запросов в минуту. Один из разработчиков настаивает на микросервисной
архитектуре «сразу правильно, чтобы потом не переписывать» — по одному сервису
на «Бронирования», «Пользователи», «Уведомления», «Биллинг».
