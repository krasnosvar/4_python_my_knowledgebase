# Other — дополнительные темы

Небольшие справочные разделы, к которым удобно возвращаться по ходу
основного курса, а не проходить их строго перед ним.

- [01_environments_and_packaging](./01_environments_and_packaging/) —
  виртуальные окружения (`venv`), `pip`, `requirements.txt` vs
  `pyproject.toml`, базовые команды Poetry, зачем нужен lock-файл и почему
  пиновать версии зависимостей.
- [02_typing_and_static_analysis](./02_typing_and_static_analysis/) —
  аннотации типов и модуль `typing`, `mypy` (и что он реально ловит, а что
  нет), линтеры и форматтеры (`ruff`, `black`) на концептуальном уровне.

## Формат

У обеих тем есть свой `README.md` с навигацией, `01_theory/`
(концентрированная теория с примерами кода прямо в тексте) и `02_examples/` (рабочие конфиги и файлы: типизированный
и нетипизированный код бок о бок, `pyproject.toml`, `requirements.txt`).
Отдельных упражнений здесь нет — это справочный материал, а не
последовательный курс.

## Как использовать

Читайте по мере необходимости, с одним исключением: `01_venv_and_pip.md`
из `01_environments_and_packaging` стоит прочитать **до** первого
`pip install -r requirements.txt` в любом разделе репозитория.

- Настраиваете окружение для нового проекта — загляните в
  `01_environments_and_packaging`.
- Подключаете mypy/ruff к проекту или разбираетесь, что означает ошибка
  типа — загляните в `02_typing_and_static_analysis`.
