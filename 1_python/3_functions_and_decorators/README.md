# Тема 3. Функции и декораторы (Functions & Decorators)

Этот раздел посвящён функциям как объектам первого класса: лямбдам,
`*args`/`**kwargs`, замыканиям, декораторам (в том числе параметризованным)
и контекст-менеджерам.

## Зачем этот раздел

В [1_python_fundamentals](../1_python_fundamentals/05_functions_basics/README.md)
функция была «блоком кода с именем». Здесь функция становится значением,
которое можно передавать, возвращать и оборачивать. На этом держится
огромная часть реального Python-кода: `@app.get(...)` в FastAPI,
`@pytest.fixture` в тестах, `@lru_cache`, `with open(...)` — всё это
декораторы и контекст-менеджеры. После раздела вы сможете читать такой код
без магии и писать свои декораторы (логирование, замер времени, повтор при
ошибке) и контекст-менеджеры (гарантированное освобождение ресурсов).

Порядок файлов важен: лямбды и `*args`/`**kwargs` идут первыми, потому что
на них опираются все примеры декораторов. Контекст-менеджеры на классах и
генераторах полностью раскрываются после разделов `4_oop` и
`5_iterators_generators` — в файле `06` есть пометка, что вернуться к ним
стоит после.

**Уже знакомы с темой?** → [CHEATSHEET.md](./CHEATSHEET.md) — lambda, `*args`/`**kwargs`, замыкания, шаблоны декораторов и контекст-менеджеров.

## Структура раздела

* **[01_theory/](./01_theory/)** — теория (разбита по подтемам):
    * [01_lambdas.md](./01_theory/01_lambdas.md) — функция как аргумент (`sorted(key=...)`, `map`, `filter`), синтаксис и ограничения `lambda`, почему PEP 8 не рекомендует присваивать лямбду имени.
    * [02_args_kwargs.md](./01_theory/02_args_kwargs.md) — упаковка/распаковка `*args`/`**kwargs`, позиционные-только и именованные-только параметры (PEP 570), почему `**kwargs` обязателен для прозрачного декоратора.
    * [03_first_class_functions_and_closures.md](./01_theory/03_first_class_functions_and_closures.md) — функции высшего порядка, что захватывает замыкание, `nonlocal`, ловушка позднего связывания в циклах.
    * [04_decorators_basics.md](./01_theory/04_decorators_basics.md) — десахаривание `@decorator`, зачем нужен `functools.wraps`, порядок применения/выполнения при стекировании декораторов.
    * [05_decorators_with_arguments.md](./01_theory/05_decorators_with_arguments.md) — декораторы-фабрики (три уровня вложенности), декораторы на основе класса (`__call__`), `functools.lru_cache` и `singledispatch`.
    * [06_context_managers.md](./01_theory/06_context_managers.md) — зачем нужен `with`, протокол `__enter__`/`__exit__`, подавление исключений, `contextlib.contextmanager`, `suppress`, `ExitStack` (класс- и генератор-варианты — после разделов 4 и 5).
* **[02_examples/](./02_examples/)** — практические примеры:
    * [01_cli_utilities.py](./02_examples/01_cli_utilities.py) — реестр CLI-команд через декоратор `@command(name)` и контекст-менеджер для временной директории.
    * [02_system_infrastructure.py](./02_examples/02_system_infrastructure.py) — декоратор `retry` с backoff поверх нестабильной операции и контекст-менеджер на классе для управляемого "соединения".
    * [03_product_backend.py](./02_examples/03_product_backend.py) — ручная мемоизация через замыкание, логирующий декоратор с `functools.wraps` и `compose`-пайплайн функций.
* **[03_exercises/](./03_exercises/)** — задачи с встроенной самопроверкой: при верном решении файл печатает `N/N проверок пройдено`, при ошибке падает с `AssertionError` и описанием, что не так:
    * `01_closure_counter` — замыкание-счётчик без утечки состояния.
    * `02_late_binding_bug` — исправление ловушки позднего связывания в цикле.
    * `03_simple_decorator` — декоратор `@timed`, сохраняющий метаданные функции.
    * `04_decorator_with_args` — декоратор-фабрика `@retry(times)`.
    * `05_args_kwargs_wrapper` — прозрачный декоратор `@log_calls` с произвольными аргументами.
    * `06_context_manager_class` — контекст-менеджер на классе с гарантированной очисткой (лучше решать после `4_oop`).
    * `07_context_manager_generator` — тот же контекст-менеджер через `@contextlib.contextmanager` (лучше решать после `5_iterators_generators`).
    * `08_lambda_sort_key` — сортировка записей по составному ключу через `lambda`.
* **[04_exercises_answers/](./04_exercises_answers/)** — эталонные решения.

## Как проходить тему

1. Прочитайте теорию по порядку от `01` до `06`, начиная с [01_lambdas.md](./01_theory/01_lambdas.md).
2. Запустите и изучите примеры из `02_examples/`:
   ```bash
   python 02_examples/02_system_infrastructure.py
   ```
3. Выполните задачи в `03_exercises/`. Запустите файл, чтобы увидеть встроенную самопроверку:
   ```bash
   python 03_exercises/03_simple_decorator.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.

## Когда двигаться дальше

Когда можете без подсказок написать декоратор с `functools.wraps`,
декоратор-фабрику с аргументами и объяснить, почему лямбды в цикле
«запоминают» последнее значение, — переходите к [4_oop](../4_oop/README.md).
К упражнениям `06`/`07` про контекст-менеджеры стоит вернуться после
разделов 4 и 5.
