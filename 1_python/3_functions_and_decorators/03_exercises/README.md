# Упражнения: функции и декораторы

Запуск задачи: `python 03_exercises/01_closure_counter.py` и т. д.

Каждый файл содержит `# TODO:` с описанием того, что нужно реализовать, и встроенную
самопроверку, которая печатает `PASS` при успехе и падает с `AssertionError`/`FAIL` при ошибке.

Ответы: эталонные решения лежат в `04_exercises_answers/` под теми же именами файлов.
