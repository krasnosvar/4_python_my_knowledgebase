# Algorithms & DSA (Python)

О-нотация как способ оценивать трудоёмкость решений, затем классические
структуры данных и алгоритмы на Python: массивы/строки, связные списки,
стек/очередь, деревья/хеш-таблицы, сортировка/поиск, рекурсия и
динамическое программирование. Материал развивает алгоритмическое
мышление — умение оценивать сложность и выбирать структуру данных под
задачу, а не просто писать код, который "работает".

## Структура

- `01_theory/` — семь тем: О-нотация; массивы/строки (два указателя,
  скользящее окно, префиксные суммы); связные списки; стек/очередь;
  деревья и хеш-таблицы (включая `heapq`); сортировка и поиск (Timsort,
  `bisect`); рекурсия и DP (мемоизация, табуляция).
- `02_examples/` — 8 runnable-примеров, по одному на тему.
- `03_exercises/` — 12 задач разного уровня сложности (лёгкий/средний/
  сложный), с `TODO` и проверками через `assert`.
- `04_exercises_answers/` — готовые решения.

## Как проходить

1. `01_big_o_notation.md` — без него сравнение "лучше/хуже" между
   решениями ниже будет интуитивным, а не осознанным.
2. Дальше темы можно проходить по порядку (`02` → `07`) — каждая опирается
   на структуры из предыдущих (например, BFS в деревьях использует ту же
   очередь, что и в теме про стек/очередь).
3. `03_exercises` организованы по возрастанию сложности — от `two_sum` до
   динамического программирования на 2D-таблице.

## Запуск примеров и упражнений

```bash
python 02_examples/01_big_o_complexity_demo/main.py
python 03_exercises/01_two_sum/main.py
```
