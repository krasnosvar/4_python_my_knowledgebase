# Тема 8. Алгоритмы и структуры данных (Algorithms & DSA)

О-нотация как способ оценивать трудоёмкость решений, затем классические
структуры данных и алгоритмы на Python: массивы/строки, связные списки,
стек/очередь, рекурсия, деревья/хеш-таблицы, сортировка/поиск,
динамическое программирование.

## Зачем этот раздел

Код, который «работает» на 100 записях, может зависнуть на миллионе — и
разница обычно не в языке, а в выбранной структуре данных и алгоритме.
Этот раздел развивает алгоритмическое мышление: умение оценить, как
решение поведёт себя при росте данных, и выбрать структуру под задачу
(список или множество, очередь или стек, перебор или бинарный поиск).
Плюс практический бонус: алгоритмические задачи — стандартная часть
технических собеседований. После раздела вы сможете оценивать сложность
своего кода в O-нотации и решать типовые задачи (два указателя, обход
дерева, мемоизация).

**Уже знакомы с темой?** → [CHEATSHEET.md](./CHEATSHEET.md) — сложность операций, паттерны (два указателя, окно, BFS/DFS, DP), сортировки.

## Как проходить

1. `01_big_o_notation.md` — без него сравнение "лучше/хуже" между
   решениями ниже будет интуитивным, а не осознанным.
2. Дальше темы проходить строго по порядку (`02` → `08`) — каждая
   опирается на предыдущие: BFS в деревьях использует очередь из `04`,
   обходы деревьев и merge sort/quicksort — рекурсию из `05`, а
   динамическое программирование в `08` — это рекурсия плюс кэш.
3. `03_exercises` организованы по возрастанию сложности — от `two_sum` до
   динамического программирования на 2D-таблице.

## Запуск примеров и упражнений

```bash
python 02_examples/01_big_o_complexity_demo/main.py
python 03_exercises/01_two_sum/main.py
```

## Когда двигаться дальше

Когда можете оценить сложность своего решения в O-нотации, без подсказки
решить задачи лёгкого и среднего уровня из `03_exercises` и объяснить,
почему `two_sum` через словарь быстрее вложенного цикла, — переходите к
[9_under_the_hood](../9_under_the_hood/). Задачи сложного уровня
(динамическое программирование) можно оставить на потом и вернуться к
ним позже.
