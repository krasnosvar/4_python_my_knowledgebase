# Упражнения: algorithms_dsa

Набор задач разного уровня сложности для развития алгоритмического
мышления — от базовой работы с массивами и стеком до динамического
программирования. Каждая задача — отдельный файл `main.py` с `TODO` и
проверками через `assert`.

Запуск задания: `python 03_exercises/01_two_sum/main.py`

Ответы: `python 04_exercises_answers/01_two_sum/main.py`

## Лёгкий уровень

1. `01_two_sum` — массивы, хеш-таблица.
2. `02_reverse_string_inplace` — строки, два указателя.
3. `03_valid_parentheses` — стек.
4. `04_reverse_linked_list` — связный список.

## Средний уровень

5. `05_detect_cycle_linked_list` — связный список, slow/fast pointer.
6. `06_merge_sorted_lists` — связный список, слияние.
7. `07_binary_search_rotated` — модифицированный бинарный поиск.
8. `08_queue_using_two_stacks` — эмуляция очереди через два стека.
9. `09_top_k_frequent` — heap + хеш-таблица.
10. `10_binary_tree_level_order` — дерево, BFS.

## Сложный уровень

11. `11_longest_common_subsequence` — динамическое программирование (2D).
12. `12_coin_change` — динамическое программирование (1D).
