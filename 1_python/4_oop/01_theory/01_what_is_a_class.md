# Что такое класс и объект

До сих пор данные и функции жили отдельно: есть словарь с данными
пользователя и есть функции, которые этот словарь принимают. Класс
позволяет объединить **данные** и **действия над ними** в одну сущность и
дать этой сущности собственный тип — так же, как у Python есть `int`,
`str` и `list`.

## Зачем это нужно

Представим, что программа работает с банковскими счетами. Без классов
счёт — это словарь, а операции — отдельные функции:

```python
account = {"owner": "Аня", "balance": 100}

def deposit(acc, amount):
    acc["balance"] += amount

deposit(account, 50)
```

Работает, но ничего не мешает написать `account["balanse"] = 0` с
опечаткой, забыть передать словарь не той структуры или изменить баланс
в обход любых проверок. С ростом программы таких «словарей с договорённо-
стями» становится десятки, и уже непонятно, какие функции к каким данным
относятся. Класс собирает данные и правила работы с ними в одном месте.

## Класс и объект (экземпляр)

* **Класс** — описание, «чертёж»: какие данные будут у объекта и что он
  умеет делать.
* **Объект** (он же **экземпляр** класса) — конкретная вещь, созданная по
  этому чертежу. Объектов одного класса может быть сколько угодно, у
  каждого свои данные.

```python
class Account:
    pass              # пустое тело: класс пока ничего не описывает

a = Account()         # создали объект — вызов класса как функции
b = Account()         # ещё один, независимый объект
type(a)               # <class '__main__.Account'>
```

Это та же идея, что и встроенные типы: `int` — класс, `5` — его экземпляр;
`list` — класс, `[1, 2]` — его экземпляр. Имена классов по соглашению
пишут с заглавной буквы в стиле `CamelCase`.

## Атрибуты: данные объекта

Данные, привязанные к объекту, называются **атрибутами**. Обращаются к
ним через точку:

```python
a = Account()
a.owner = "Аня"
a.balance = 100
print(a.owner, a.balance)   # Аня 100
```

Задавать атрибуты вручную после создания неудобно и ненадёжно — легко
забыть один. Поэтому их задают в специальном методе `__init__`.

## `__init__` и `self`

`__init__` (два подчёркивания с каждой стороны) — метод, который Python
вызывает **автоматически** сразу после создания объекта. Аргументы,
переданные при создании, попадают в него:

```python
class Account:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

a = Account("Аня", 100)     # Python вызовет __init__(a, "Аня", 100)
b = Account("Борис", 0)
print(a.balance, b.balance) # 100 0
```

`self` — первый параметр любого метода: это **сам объект**, для которого
метод вызван. При вызове его не передают явно — Python подставляет его
сам. Запись `self.owner = owner` значит «сохранить значение параметра
`owner` в атрибут `owner` этого конкретного объекта». Имя `self` — строгое
соглашение (технически можно назвать иначе, но так никто не делает).

## Методы: действия объекта

**Метод** — функция, объявленная внутри класса. Она получает объект через
`self` и может читать и менять его атрибуты:

```python
class Account:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            print("Сумма должна быть положительной")
            return
        self.balance += amount

    def describe(self):
        return f"{self.owner}: {self.balance} руб."

a = Account("Аня", 100)
a.deposit(50)               # Python вызовет Account.deposit(a, 50)
a.deposit(-10)              # Сумма должна быть положительной
print(a.describe())         # Аня: 150 руб.
```

Теперь проверка суммы живёт рядом с данными: любой код, который
пополняет счёт через `deposit`, получает её автоматически.

Вы уже постоянно пользовались методами встроенных классов:
`text.upper()`, `items.append(x)`, `d.get(key)` — это ровно тот же
механизм, только классы `str`, `list`, `dict` написаны за вас.

## Подсказки типов в примерах дальше

В следующих файлах раздела у параметров и методов появятся аннотации:

```python
def __init__(self, owner: str, balance: float) -> None:
```

`: str` и `-> None` — необязательные подсказки типов: Python их не
проверяет при выполнении, они нужны читателю и инструментам вроде
редактора (подробно — в
[1_python_fundamentals/05_functions_basics](../../1_python_fundamentals/05_functions_basics/01_theory/01_functions_basics.md)).
`-> None` значит «метод ничего не возвращает». Тип можно писать и в
кавычках (`-> "Vector"`), когда класс ссылается сам на себя внутри своего
же описания.

## Проверить понимание

Что напечатает код?

```python
class Counter:
    def __init__(self):
        self.value = 0

    def increment(self):
        self.value += 1

a = Counter()
b = Counter()
a.increment()
a.increment()
b.increment()
print(a.value, b.value)
```

<details>
<summary>Разбор</summary>

Напечатает `2 1`. `a` и `b` — два независимых объекта одного класса, у
каждого свой атрибут `value`. `a.increment()` меняет только `a.value`
(внутри метода `self` — это `a`), а `b.increment()` — только `b.value`.

</details>
