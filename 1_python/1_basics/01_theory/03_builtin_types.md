# Базовые встроенные типы: int, float, bool, None

## `int` — целые числа произвольной точности

В Python `int` не переполняется: при превышении диапазона фиксированной разрядности (как `int64` в других языках) число автоматически расширяется, занимая больше памяти.

```python
huge = 2 ** 1000          # обычный int, никакого overflow
print(huge.bit_length())  # 1000
```

Это удобно, но не бесплатно: операции над очень большими числами медленнее, чем над числами, помещающимися в машинное слово, так как под капотом используется собственная реализация длинной арифметики.

## `float` — IEEE 754 double precision и его подводные камни

`float` в Python — это 64-битное число с плавающей запятой (IEEE 754), с теми же ограничениями точности, что и в большинстве языков:

```python
0.1 + 0.2 == 0.3   # False!
0.1 + 0.2          # 0.30000000000000004
```

Причина — `0.1` и `0.2` не представимы точно в двоичной системе (как `1/3` не представимо точно в десятичной). Практические следствия:

* Не сравнивайте float через `==` — используйте допуск (`math.isclose(a, b)`).
* Для денег и других величин, где точность критична, используйте `decimal.Decimal` или целые (например, храните копейки, а не рубли).

```python
import math
math.isclose(0.1 + 0.2, 0.3)   # True
```

## `bool` — подкласс `int`

`bool` в Python — это подтип `int` с двумя возможными значениями, `True` и `False`, которые численно равны `1` и `0`:

```python
isinstance(True, int)   # True
True == 1                # True
True + True              # 2 (!) — арифметика работает
[1, 2, 3][True]           # 2 — bool можно использовать как индекс
```

Это не просто курьёз: из-за этого `sum(condition(x) for x in items)` — идиоматичный способ посчитать количество элементов, удовлетворяющих условию, ведь `True` в сумме считается как `1`.

## `None` — единственный синглтон отсутствия значения

`None` — единственный экземпляр типа `NoneType`, существующий в интерпретаторе. Используется как:

* значение по умолчанию для «нет значения» (в отличие от `0`, `""`, `False`, которые являются полноценными значениями своих типов);
* сигнал «функция ничего явно не вернула» (функция без `return` или с голым `return` возвращает `None`).

Проверка `is None`, а не `== None`, — идиома, потому что:

1. `None` — синглтон, сравнение идентичности корректно и быстрее.
2. Некоторые объекты могут переопределить `__eq__` так, что `obj == None` вернёт неожиданное значение (например, `True` для «пустых» пользовательских объектов), тогда как `obj is None` всегда однозначен.

```python
def find_user(user_id: int) -> "User | None":
    ...

user = find_user(42)
if user is None:
    print("Пользователь не найден")
```
