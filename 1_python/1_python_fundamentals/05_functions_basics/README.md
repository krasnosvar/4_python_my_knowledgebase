# Тема 1.5. Функции

Объявление через `def`, параметры и аргументы, `return`, значения по
умолчанию, позиционные и именованные аргументы, docstring, аннотации типов.

## Зачем этот раздел

Когда один и тот же кусок кода нужен в нескольких местах, его
оформляют в функцию: даёт имя, принимает входные данные, возвращает
результат. Все упражнения этого репозитория — функции, которые нужно
дописать, так что после этой темы станет полностью понятно, как устроены
файлы упражнений из тем 1.1–1.4. Здесь же — аннотации типов (`x: int`,
`-> str`), которые встречаются во всём остальном коде базы.

**Уже знакомы с темой?** → [CHEATSHEET.md](../CHEATSHEET.md#15-функции) — раздел «1.5 Функции» общей шпаргалки основ.

## Как проходить

1. Прочитайте теорию:
   [01_functions_basics.md](./01_theory/01_functions_basics.md).
2. Запустите пример:
   ```bash
   python3 02_examples/01_temperature_converter.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python3 03_exercises/01_is_palindrome.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
