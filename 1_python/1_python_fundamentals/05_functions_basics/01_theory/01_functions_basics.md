# Функции

Функция — это именованный кусок кода, который можно вызвать много раз с
разными данными, не переписывая его заново. Она принимает входные значения
(параметры) и может вернуть результат.

## Объявление и вызов

Функция объявляется ключевым словом `def`, именем и списком параметров в
скобках. Тело функции — это блок с отступом, как у `if`/`for` (раздел 4):

```python
def greet(name):
    print(f"Привет, {name}!")

greet("Alex")   # вызов функции - выведет "Привет, Alex!"
greet("Nina")   # тот же код выполнится снова с другим значением
```

`name` здесь — **параметр**: имя, под которым внутри функции доступно
значение, переданное при вызове. `"Alex"` при вызове — **аргумент**:
конкретное значение, переданное на место параметра.

## return

Если функция должна не просто напечатать что-то, а вернуть значение,
которое можно сохранить в переменную или использовать дальше, используется
`return`:

```python
def add(a, b):
    return a + b

result = add(2, 3)   # result == 5
print(add(10, 20))   # можно использовать результат сразу, без переменной
```

Как только выполняется `return`, функция немедленно завершается — код
после `return` в этом же вызове не выполнится. Если в функции нет `return`,
она возвращает `None`:

```python
def say_hello():
    print("Привет")
    # нет return

value = say_hello()   # напечатает "Привет", value станет None
```

## Параметры по умолчанию

Параметру можно задать значение по умолчанию — тогда при вызове его можно
не указывать:

```python
def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

greet("Alex")              # "Привет, Alex!" - greeting не указан, взято значение по умолчанию
greet("Alex", "Здравствуй") # "Здравствуй, Alex!" - greeting указан явно
```

Параметры без значения по умолчанию называются обязательными — их нужно
передать всегда, и они должны идти в объявлении функции раньше параметров
со значением по умолчанию.

⚠️ Значением по умолчанию не стоит делать изменяемый объект (список,
словарь) — это классическая ловушка Python: список-по-умолчанию создаётся
**один раз** при объявлении функции и делится между всеми вызовами, которые
не передали свой список явно. Этот случай подробно разобран в разделе
[2_basics](../../../2_basics/README.md), когда станет понятно, что такое
изменяемость.

## Позиционные и именованные аргументы

Аргументы можно передавать по позиции (в том порядке, в каком объявлены
параметры) или по имени — тогда порядок не важен:

```python
def describe_pet(name, species):
    return f"{name} - это {species}"

describe_pet("Барсик", "кот")              # позиционные: name="Барсик", species="кот"
describe_pet(species="кот", name="Барсик") # именованные: порядок не важен
```

## Docstring

Строка документации сразу после `def` (в тройных кавычках) описывает, что
делает функция — это не комментарий `#`, а часть самой функции, доступная
через `help()`:

```python
def square(number):
    """Возвращает квадрат числа."""
    return number ** 2
```

## Аннотации типов

В упражнениях этого репозитория и почти во всех следующих разделах функции
выглядят так:

```python
def apply_discount(price: float, discount_percent: float = 10) -> float:
    return price - price * discount_percent / 100
```

`: float` после параметра и `-> float` после скобок — это **аннотации
типов** (type hints): подсказка читателю и редактору кода, какого типа
ожидается значение и что функция вернёт. Главное, что нужно знать:

- аннотации **необязательны** — функция без них работает точно так же;
- Python их **не проверяет** при запуске: вызов `apply_discount("сто")`
  не будет остановлен из-за аннотации, ошибка случится (или не случится)
  только в самой арифметике;
- проверяют их отдельные инструменты (например, `mypy`) и редакторы кода,
  подсвечивая несоответствия ещё до запуска.

Поэтому дальше в репозитории аннотации стоят почти везде: читай их как
документацию «что сюда передавать». Подробнее — в
[other/02_typing_and_static_analysis](../../../../other/02_typing_and_static_analysis/).

## Проверить понимание

Что вернёт вызов `describe(age=20)` и почему, если функция объявлена так:

```python
def describe(name="Аноним", age=0):
    return f"{name}, {age} лет"
```

<details>
<summary>Разбор</summary>

Вернёт `"Аноним, 20 лет"`. Параметр `age` передан именованным аргументом
(`age=20`), поэтому он равен `20`. Параметр `name` не был передан вообще —
ни по позиции, ни по имени, — значит для него используется значение по
умолчанию `"Аноним"`. Именованные аргументы можно передавать выборочно, не
указывая остальные, если у них есть значение по умолчанию.

</details>
