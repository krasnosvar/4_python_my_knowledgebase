# Тема 1.8. Модули и import

Как подключить готовый код из другого файла или стандартной библиотеки:
`import x`, `from x import y`, `import x as y`, модули `math`, `random`,
`decimal` и `copy`, смысл `if __name__ == "__main__":`, что такое пакет и
откуда берутся сторонние библиотеки. Завершающая тема основ языка.

## Зачем этот раздел

Никто не пишет всё с нуля: квадратный корень, случайные числа, точные
десятичные дроби и глубокое копирование коллекций уже есть в стандартной
библиотеке, а свой код удобно разложить по нескольким файлам. Эта тема учит
подключать готовый код через `import` и объясняет строку
`if __name__ == "__main__":`, которая стоит в конце каждого упражнения.
После неё вы сможете использовать стандартные модули и понимать устройство
любого скрипта в этой базе.

## Как проходить

1. Прочитайте теорию:
   [01_modules_and_imports.md](./01_theory/01_modules_and_imports.md).
2. Запустите пример:
   ```bash
   python3 02_examples/01_dice_and_geometry.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python3 03_exercises/01_circle_area.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
