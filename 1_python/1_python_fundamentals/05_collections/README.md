# Тема 1.5. Составные типы данных (Collections)

Четыре основные коллекции Python — `list`, `tuple`, `set`, `dict`:
синтаксис, индексация и срезы, основные методы, изменяемость и общие
ссылки (`is` против `==`, копирование), а также компактное построение
коллекций через comprehensions.

## Зачем этот раздел

В реальных программах данные редко хранятся по одному числу в отдельной
переменной: у пользователя есть список заказов, у заказа — словарь полей,
а у фильтра — множество допустимых тегов. Эта тема учит выбирать подходящую
коллекцию под задачу, работать со списками, кортежами, множествами и
словарями и не попадаться в ловушку общих ссылок, когда изменение одного
списка внезапно меняет «другой».

## Как проходить

1. Прочитайте теорию по порядку от `01` до `03`.
2. Запустите пример:
   ```bash
   python3 02_examples/01_orders_and_comprehensions.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python3 03_exercises/01_set_dedup.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
