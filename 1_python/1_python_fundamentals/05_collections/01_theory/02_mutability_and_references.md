# Изменяемость, идентичность и общие ссылки

Любое значение в Python — **объект** в памяти. У каждого объекта есть три
свойства:

- **идентичность** (identity) — уникальный номер объекта в памяти; узнать
  его можно встроенной функцией `id(x)`;
- **тип** — `int`, `str`, `list` и т.д. (`type(x)`);
- **значение** — содержимое объекта (`42`, `"hi"`, `[1, 2]`).

Идентичность и тип объекта после создания не меняются никогда. А вот
значение у одних типов менять можно, у других — нельзя.

## Изменяемые и неизменяемые типы

- **Неизменяемые (immutable)**: `int`, `float`, `bool`, `str`, `tuple`,
  `None`. Изменить такой объект «на месте» нельзя — любая операция вроде
  `s += " world"` или `t + (4,)` создаёт в памяти **новый** объект с новым
  `id()`, а переменная просто начинает ссылаться на него.
- **Изменяемые (mutable)**: `list`, `dict`, `set`. Их содержимое меняется
  прямо внутри существующего объекта, при этом его `id()` остаётся прежним.

```python
s = "hello"
before_str_id = id(s)
s += " world"                 # создана НОВАЯ строка
print(id(s) == before_str_id) # False — это уже другой объект

lst = [1, 2, 3]
before_list_id = id(lst)
lst.append(4)                  # изменён ТОТ ЖЕ список на месте
print(id(lst) == before_list_id) # True — объект остался тем же самым
```

## `is` против `==`

- `==` сравнивает **значения**: «одинаковое ли содержимое».
- `is` сравнивает **идентичность**: «это один и тот же объект в памяти?»
  (то же самое, что `id(a) == id(b)`).

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True  — содержимое списков одинаковое
print(a is b)   # False — это два разных списка в памяти
```

Правило:

- Числа, строки, списки, словари, кортежи и множества сравнивайте **только
  через `==`**.
- Оператор `is` используйте для проверки на `None` (`if user is None:`,
  `if user is not None:`), потому что объект `None` во всей программе
  существует в единственном экземпляре.

## Общие ссылки (aliasing) и копирование

Переменная в Python — это **имя**, привязанное к объекту, а не «коробка», в
которую скопировали данные. Присваивание `alias = original` не создаёт копию
списка — оно просто даёт тому же самому списку второе имя:

```python
original = [1, 2, 3]
alias = original       # alias и original указывают на ОДИН И ТОТ ЖЕ список
alias.append(4)
print(original)        # [1, 2, 3, 4] — изменение видно через оба имени!
```

### Ловушка с вложенными списками: `[row] * 3`

То же самое происходит при умножении списка, содержащего другой список:

```python
row = [0, 0, 0]
grid = [row] * 3       # в grid лежат три ссылки на ОДИН И ТОТ ЖЕ список row
grid[0][0] = 1
print(grid)            # [[1, 0, 0], [1, 0, 0], [1, 0, 0]] — поменялось во всех строках!

grid_ok = []
for _ in range(3):
    grid_ok.append([0, 0, 0])   # правильно: на каждом шаге создаётся новый список
grid_ok[0][0] = 1
print(grid_ok)         # [[1, 0, 0], [0, 0, 0], [0, 0, 0]]
```

(`_` в `for _ in range(3)` — общепринятое имя переменной цикла, когда сам
счётчик внутри тела не используется.)

### Как скопировать коллекцию

- **Поверхностная копия (shallow copy):** `original[:]`, `list(original)`
  или `original.copy()` создают новый внешний список. Если внутри лежат
  только неизменяемые значения (числа, строки, кортежи), этого полностью
  достаточно.
- **Глубокая копия (deep copy):** если внутри списка лежат другие списки
  или словари, поверхностная копия скопирует только внешний список, а
  вложенные останутся общими. Для полного копирования всех уровней
  вложенности используется функция `copy.deepcopy()` из стандартного модуля
  `copy` (как работают модули и `import`, подробно разбирается в
  [теме 1.8](../../08_modules_and_imports/01_theory/01_modules_and_imports.md)).

## Проверить понимание

Что выведет этот код и почему?

```python
first = [10, 20]
second = first[:]
second.append(30)
print(first, second)
```

<details>
<summary>Разбор</summary>

Выведет `[10, 20] [10, 20, 30]`. Срез `first[:]` создал **новый** список с
теми же элементами, поэтому `second.append(30)` изменил только `second`, не
затронув `first`.

</details>
