# List, dict и set comprehensions

Comprehension (генераторное выражение для коллекции) — компактный способ
построить новый список, словарь или множество из другой последовательности
в одну строку вместо ручного цикла с `.append()` или `.add()`.

## Синтаксис

Общая форма для списка: `[выражение for элемент in источник if условие]`.
Часть `if условие` необязательна и работает как фильтр:

```python
# Ручной цикл:
squares = []
for x in range(6):
    if x % 2 == 0:
        squares.append(x ** 2)

# То же самое через list comprehension:
squares = [x ** 2 for x in range(6) if x % 2 == 0]   # [0, 4, 16]
```

По тому же принципу строятся словари и множества — меняются только скобки:

```python
words = ["кот", "слон", "кит", "собака"]

# dict comprehension — {ключ: значение for ...}
word_lengths = {word: len(word) for word in words}
# {'кот': 3, 'слон': 4, 'кит': 3, 'собака': 6}

# set comprehension — {выражение for ...} (дубли автоматически исчезнут)
unique_lengths = {len(word) for word in words}
# {3, 4, 6}
```

> Круглые скобки `(x ** 2 for x in range(6))` создают **не** кортеж, а
> ленивый генератор — он подробно разбирается в разделе
> [4_iterators_generators](../../../4_iterators_generators/). Чтобы получить
> именно кортеж, оберните выражение в `tuple(...)`.

## Вложенные comprehensions

Внутри comprehension может быть два цикла `for` подряд. Порядок записи
`for` точно такой же, как если бы вы писали обычные вложенные циклы сверху
вниз:

```python
matrix = [[1, 2], [3, 4], [5, 6]]

flat = [x for row in matrix for x in row]   # [1, 2, 3, 4, 5, 6]
# эквивалентно:
# flat = []
# for row in matrix:
#     for x in row:
#         flat.append(x)
```

Если же вложен сам квадратный список `[[...] for ...]`, то на каждом шаге
внешнего цикла создаётся новая строка матрицы:

```python
grid = [[0] * 3 for _ in range(3)]   # 3 независимых списка [0, 0, 0]
```

## Оператор `:=` (walrus) внутри comprehension

Оператор присваивания внутри выражения `:=` (с Python 3.8) позволяет
вычислить значение один раз в условии `if` и тут же использовать его в
левой части, не делая одну и ту же работу дважды:

```python
raw_inputs = ["  привет ", "   ", " мир  "]

# strip() убирает пробелы по краям строки; берём только непустые после очистки:
cleaned = [stripped for s in raw_inputs if (stripped := s.strip()) != ""]
# ['привет', 'мир']
```

## Когда comprehension — плохая идея

Comprehension хорош, когда вся операция читается с первого взгляда:
«преобразовать каждый элемент и, возможно, отфильтровать». Если внутри
появляется сложная логика, несколько уровней вложенности или изменения
внешних переменных — пишите обычный цикл `for`: читаемость всегда важнее
экономии трёх строк.

## Проверить понимание

Какой словарь построит выражение ниже?

```python
numbers = [1, 2, 3, 4]
result = {n: n * 10 for n in numbers if n > 2}
```

<details>
<summary>Разбор</summary>

Построит `{3: 30, 4: 40}`. Фильтр `if n > 2` оставляет только числа `3` и
`4`, а выражение `n: n * 10` кладёт каждое из них в словарь как ключ со
значением в 10 раз больше.

</details>
