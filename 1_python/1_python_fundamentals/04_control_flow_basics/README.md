# Тема 1.4. Ветвления и циклы

Главное правило Python — отступы определяют блок кода. `if`/`elif`/`else`,
truthy/falsy значения, цикл `for` (перебор элементов, не счётчик), `range()`,
цикл `while`, `break` и `continue`.

## Зачем этот раздел

До этой темы программа выполняется строго сверху вниз, строка за
строкой. Реальному коду нужно принимать решения («если баллов больше 90 —
оценка A») и повторять действия («для каждого заказа посчитать сумму»).
Эта тема учит `if`/`elif`/`else` и циклам `for`/`while`, а заодно главному
правилу синтаксиса Python — отступы определяют блок кода. Здесь же впервые
появляется список `[...]` — в минимальном объёме, нужном для цикла.

1. Прочитайте теорию:
   [01_control_flow_basics.md](./01_theory/01_control_flow_basics.md).
2. Запустите пример:
   ```bash
   python3 02_examples/01_grade_calculator.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
