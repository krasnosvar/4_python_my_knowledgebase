# Ветвления и циклы

До сих пор код выполнялся строго сверху вниз, по одному разу на строку.
Ветвления (`if`) позволяют выполнить код только при определённом условии,
а циклы (`for`, `while`) — выполнить один и тот же код много раз.

## Главное правило Python: отступы определяют блок кода

В большинстве языков блок кода ограничивают фигурные скобки `{}`. В Python
границу блока задаёт **отступ** (обычно 4 пробела). Строка, после которой
стоит `:`, открывает новый блок — все последующие строки с большим
отступом принадлежат этому блоку, пока отступ не вернётся к прежнему
уровню:

```python
if True:
    print("внутри блока if")   # отступ 4 пробела - часть блока if
    print("тоже внутри")       # тот же отступ - тоже часть блока
print("снаружи блока if")      # отступ вернулся к 0 - блок закончился
```

Смешивание пробелов и табов или непоследовательные отступы — это ошибка
`IndentationError`, а не просто «некрасивый код», как в языках со
скобками. Договорись сам с собой использовать только пробелы (обычно 4) и
не отступай от этого.

## if / elif / else

```python
age = 20

if age < 18:
    print("несовершеннолетний")
elif age < 65:
    print("взрослый")
else:
    print("пенсионного возраста")
```

Python проверяет условия по порядку сверху вниз и выполняет **только
первый** подходящий блок, остальные пропускает. `elif` (сокращение от
"else if") и `else` необязательны — можно обойтись одним `if`.

### Truthy и falsy значения

В условии `if` можно использовать не только `bool`, но и любое значение —
Python сам решает, считать ли его «истинным» (truthy) или «ложным»
(falsy). Falsy-значения: `0`, `0.0`, `""` (пустая строка), `None`, пустые
коллекции (`[]`, `{}`). Всё остальное — truthy:

```python
items = []
if items:
    print("есть элементы")
else:
    print("список пуст")   # выполнится: пустой список - falsy
```

## Цикл for

`for` в Python перебирает элементы **любой последовательности** — списка,
строки, результата `range()`. Это не «счётчик от A до B», как в некоторых
других языках, а буквально «для каждого элемента»:

```python
for letter in "abc":
    print(letter)            # a, затем b, затем c - каждая на своей строке

fruits = ["яблоко", "груша", "слива"]
for fruit in fruits:
    print(fruit)
```

Чтобы пройтись именно по числам, используется `range()`:

```python
for i in range(5):       # 0, 1, 2, 3, 4 - до 5, не включая 5
    print(i)

for i in range(2, 5):    # 2, 3, 4 - с 2 по 5, не включая 5
    print(i)
```

## Цикл while

`while` повторяет блок, пока условие истинно. В отличие от `for`, число
повторений заранее неизвестно — оно зависит от того, когда условие станет
ложным:

```python
count = 0
while count < 3:
    print(f"попытка {count}")
    count += 1    # обязательно менять условие внутри цикла,
                  # иначе цикл никогда не остановится
```

Если забыть `count += 1`, условие `count < 3` останется истинным навсегда
— это называется бесконечным циклом, и программа зависнет.

## break и continue

`break` немедленно останавливает цикл целиком. `continue` пропускает
оставшуюся часть текущей итерации и переходит к следующей:

```python
for i in range(10):
    if i == 5:
        break          # цикл полностью остановится на i == 5
    print(i)            # выведет 0, 1, 2, 3, 4

for i in range(5):
    if i == 2:
        continue        # пропустит печать именно для i == 2
    print(i)             # выведет 0, 1, 3, 4 (без 2)
```

## Проверить понимание

Сколько раз выполнится тело цикла и что будет напечатано?

```python
total = 0
for number in [10, 20, 30]:
    if number == 20:
        continue
    total += number
print(total)
```

<details>
<summary>Разбор</summary>

Напечатает `40`. Цикл проходит по всем трём числам (10, 20, 30). Когда
`number == 20`, срабатывает `continue` — строка `total += number`
пропускается именно для этой итерации, но цикл продолжается дальше (в
отличие от `break`, который бы остановил цикл целиком). В итоге `total`
получает только 10 и 30: `10 + 30 = 40`.

</details>
