# Тема 1.6. Функции

Объявление через `def`, параметры и аргументы, `return`, значения по
умолчанию (и ловушка с изменяемым списком по умолчанию), позиционные и
именованные аргументы, docstring, аннотации типов.

## Зачем этот раздел

Когда один и тот же кусок кода нужен в нескольких местах, его оформляют в
функцию: она принимает входные данные и возвращает результат. Все
упражнения этого репозитория — функции, которые нужно дописать, так что
после этой темы станет полностью понятно, как устроены файлы упражнений из
тем 1.1–1.5. Здесь же — аннотации типов (`x: int`, `-> str`), которые
встречаются во всём остальном коде базы.

**Уже знакомы с темой?** →
[CHEATSHEET.md](../CHEATSHEET.md#16-функции) — раздел «1.6 Функции» общей
шпаргалки основ.

## Как проходить

1. Прочитайте теорию:
   [01_functions_basics.md](./01_theory/01_functions_basics.md).
2. Запустите пример:
   ```bash
   python3 02_examples/01_temperature_converter.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python3 03_exercises/01_is_palindrome.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.

## Когда двигаться дальше

Если вы можете объявить функцию с параметром по умолчанию, объяснить,
почему `def f(items=[])` — ошибка, и прочитать аннотации типов — переходите
к теме [1.7. Исключения](../07_exceptions/README.md): что делать, когда код
падает с ошибкой.
