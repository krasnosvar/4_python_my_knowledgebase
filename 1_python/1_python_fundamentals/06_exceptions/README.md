# Тема 1.6. Исключения

Что происходит, когда код падает, как читать traceback, как перехватить
ожидаемую ошибку через `try`/`except` и как выбросить свою через `raise`.
Без этой темы невозможно читать код дальше в репозитории: `try`/`except`
встречается почти в каждом следующем разделе.

## Зачем этот раздел

Код неизбежно падает: пользователь ввёл буквы вместо числа, файла нет,
делитель равен нулю. Эта тема учит читать traceback (где и почему
упало), перехватывать ожидаемые ошибки через `try`/`except` и сообщать о
своих ошибках через `raise`. После неё вы сможете написать цикл, который
переспрашивает ввод до корректного числа, и поймёте, почему упражнения
до реализации падают с `NotImplementedError`.

**Уже знакомы с темой?** → [CHEATSHEET.md](../CHEATSHEET.md#16-исключения) — раздел «1.6 Исключения» общей шпаргалки основ.

## Как проходить

1. Прочитайте теорию:
   [01_exceptions.md](./01_theory/01_exceptions.md).
2. Запустите пример:
   ```bash
   python3 02_examples/01_safe_calculator.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python3 03_exercises/01_safe_int.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.

## Когда двигаться дальше

Если ты можешь по traceback найти строку с ошибкой, перехватить
конкретный тип исключения и объяснить, почему голый `except:` опасен —
переходи к теме [1.7. Модули и import](../07_modules_and_imports/README.md).
