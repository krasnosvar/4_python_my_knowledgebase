# Упражнения: операторы и выражения

Каждое упражнение — самостоятельный скрипт с `# TODO:` пометками. Реализуйте
недостающую часть и запустите файл напрямую:

```bash
python3 03_exercises/01_is_eligible.py
```

Пока `TODO` не реализован, скрипт упадёт с `NotImplementedError`. Если
ответ неверный, самопроверка остановится на первой несовпавшей проверке с
`AssertionError` — в последней строке traceback написано, что ожидалось и
что получено. После правильной реализации самопроверка печатает `PASS` по
каждой проверке и итог вида `3/3 проверок пройдено`.

## Как устроен файл упражнения

Файл упражнения использует несколько конструкций, которые подробно
разбираются только в темах 1.6–1.8. Пока их не нужно понимать целиком —
достаточно знать, где ваш участок кода:

```python
def sum_as_numbers(first: str, second: str) -> int:   # не трогать
    raise NotImplementedError("...")                  # <- заменить эту строку

def _self_check() -> None:                            # не трогать
    ...

if __name__ == "__main__":                            # не трогать
    _self_check()
```

- **Что редактировать:** только строку (или строки) под описанием `TODO`
  внутри функции — строку с `raise NotImplementedError(...)`. Замените её
  на `return <ваше выражение>`: значение после слова `return` — это ответ
  функции. Например, `return 2 + 3`. Имена в скобках после имени функции
  (`first`, `second`) — это входные данные, с ними можно работать как с
  обычными переменными.
- **Что не трогать:** строку `def ...` с именем функции, функцию
  `_self_check()` и блок `if __name__ == "__main__":` в конце файла — это
  самопроверка, она вызывает вашу функцию и сравнивает ответ с ожидаемым.
- **Что это за слова:** `def` и `return` (а также записи вида `first: str`
  и `-> int` — аннотации типов) объяснены в
  [теме 1.6](../../06_functions_basics/), `raise` и `NotImplementedError` —
  в [теме 1.7](../../07_exceptions/), `if __name__ == "__main__":` — в
  [теме 1.8](../../08_modules_and_imports/). Квадратные скобки `[...]` в
  самопроверке — это список, коротко он представлен в
  [теме 1.4](../../04_control_flow/01_theory/01_control_flow.md) и подробно
  в [теме 1.5](../../05_collections/).

Эталонные решения — в [04_exercises_answers/](../04_exercises_answers/), с
теми же именами файлов.
