# Тема 02. Операторы и выражения

Арифметические, сравнения и логические операторы, приоритет операторов,
конкатенация строк и f-строки, составное присваивание (`+=` и аналоги).

## Структура раздела

- **[01_theory/](./01_theory/)** — теория:
  - [01_operators_and_expressions.md](./01_theory/01_operators_and_expressions.md) —
    арифметика, сравнения, логика, приоритет операторов, f-строки,
    составное присваивание.
- **[02_examples/](./02_examples/)** — практические примеры:
  - [01_shopping_cart_total.py](./02_examples/01_shopping_cart_total.py) —
    подсчёт стоимости корзины, разложение секунд на минуты через `//` и `%`.
- **[03_exercises/](./03_exercises/)** — задачи с самопроверкой `PASS`/`FAIL`:
  - `01_is_eligible` — логические операторы и сравнения.
  - `02_format_report` — сборка строки через f-строку.
- **[04_exercises_answers/](./04_exercises_answers/)** — эталонные решения.

## Как проходить тему

1. Прочитайте теорию:
   [01_operators_and_expressions.md](./01_theory/01_operators_and_expressions.md).
2. Запустите пример:
   ```bash
   python 02_examples/01_shopping_cart_total.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python 03_exercises/01_is_eligible.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.

Дальше: [ввод и вывод](../03_input_output/).
