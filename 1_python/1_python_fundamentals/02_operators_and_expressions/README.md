# Тема 1.2. Операторы и выражения

Арифметические, сравнения и логические операторы, приоритет операторов,
конкатенация строк и f-строки, составное присваивание (`+=` и аналоги).

## Зачем этот раздел

Переменные сами по себе ничего не считают — нужны операторы: сложить
цены, проверить «возраст не меньше 18 и есть согласие», собрать строку
отчёта. Эта тема учит записывать вычисления и условия так, чтобы Python
понял их так же, как вы (с учётом приоритета операторов). После темы вы
сможете посчитать итог корзины, разложить секунды на минуты через `//` и
`%` и собрать читаемую строку через f-строку.

**Уже знакомы с темой?** → [CHEATSHEET.md](../CHEATSHEET.md#12-операторы-и-выражения) — раздел «1.2 Операторы и выражения» общей шпаргалки основ.

## Как проходить

1. Прочитайте теорию:
   [01_operators_and_expressions.md](./01_theory/01_operators_and_expressions.md).
2. Запустите пример:
   ```bash
   python3 02_examples/01_shopping_cart_total.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python3 03_exercises/01_is_eligible.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
