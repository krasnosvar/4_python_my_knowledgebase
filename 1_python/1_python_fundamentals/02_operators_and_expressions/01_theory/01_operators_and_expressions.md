# Операторы и выражения

Выражение — это кусок кода, который вычисляется и даёт значение: `2 + 3`,
`age >= 18`, `name + "!"`. Оператор — это символ, который говорит, какое
именно вычисление сделать.

## Арифметические операторы

```python
7 + 3   # 10 - сложение
7 - 3   # 4  - вычитание
7 * 3   # 21 - умножение
7 / 3   # 2.3333333333333335 - деление, всегда возвращает float
7 // 3  # 2  - целочисленное деление (отбрасывает дробную часть)
7 % 3   # 1  - остаток от деления
7 ** 3  # 343 - возведение в степень
```

`/` в Python 3 всегда возвращает `float`, даже если числа делятся без
остатка: `10 / 2` даёт `5.0`, а не `5`. Если нужен именно `int`, используй
`//`.

## Операторы сравнения

Результат сравнения — всегда `bool` (`True` или `False`):

```python
5 == 5   # True  - равно
5 != 3   # True  - не равно
5 > 3    # True  - больше
5 < 3    # False - меньше
5 >= 5   # True  - больше либо равно
5 <= 3   # False - меньше либо равно
```

`==` сравнивает **значения**, а не ссылается ли переменная на один и тот же
объект в памяти (это отдельная тема `is` против `==`, см. раздел
[2_basics](../../../2_basics/01_theory/03_mutability_and_identity.md) —
но для чисел, строк и булевых значений на этом уровне безопасно всегда
использовать именно `==`).

## Логические операторы

```python
True and False   # False - оба должны быть True
True or False     # True  - достаточно одного True
not True          # False - инверсия
```

Логические операторы часто комбинируют результаты сравнений:

```python
age = 25
is_adult_but_not_senior = age >= 18 and age < 65
```

## Приоритет операторов

Как и в математике, у операторов есть приоритет: `**` выше, чем `*`/`/`,
которые выше, чем `+`/`-`, которые выше, чем сравнения, которые выше, чем
`and`/`or`. Скобки `()` всегда выполняются первыми и их стоит использовать,
если есть сомнение, чтобы не держать таблицу приоритетов в голове:

```python
2 + 3 * 4        # 14, не 20: сначала умножение
(2 + 3) * 4      # 20: скобки меняют порядок
```

## Строки: конкатенация и f-строки

Оператор `+` для строк означает склеивание (конкатенацию), не сложение:

```python
"Привет, " + "мир"  # "Привет, мир"
```

Для вставки значений внутрь строки удобнее **f-строки** (formatted string
literals) — префикс `f` перед кавычками и `{выражение}` внутри:

```python
name = "Alex"
age = 25
message = f"{name}, тебе {age} лет"   # "Alex, тебе 25 лет"
message = f"Через год будет {age + 1}"  # внутри {} можно писать выражения
```

f-строка удобнее, чем склеивание через `+`, потому что не требует вручную
преобразовывать числа в строки функцией `str()`.

## Составное присваивание

Изменить значение переменной на основе её же текущего значения можно короче,
чем `x = x + 1`:

```python
x = 10
x += 1   # то же самое, что x = x + 1; теперь x == 11
x -= 1   # x == 10
x *= 2   # x == 20
```

## Проверить понимание

Что вернёт выражение `10 // 3 == 3 and 10 % 3 == 1`, и почему оба условия
истинны одновременно?

<details>
<summary>Разбор</summary>

Вернёт `True`. `10 // 3` — целая часть от деления 10 на 3, то есть `3`
(3 помещается в 10 три раза). `10 % 3` — то, что осталось после этого: `10 -
3*3 = 1`. Оба условия проверяют взаимодополняющие части одного и того же
деления: `//` даёт частное, `%` — остаток, и `(10 // 3) * 3 + (10 % 3)`
всегда равно исходному числу 10.

</details>
