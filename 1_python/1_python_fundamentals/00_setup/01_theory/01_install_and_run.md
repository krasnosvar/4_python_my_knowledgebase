# Установка Python и первый запуск

Прежде чем писать код, нужно две вещи: установленный Python и умение
запустить файл с кодом из терминала. Этот урок — про это и только про это.

## Что такое Python «на компьютере»

Python — это программа-интерпретатор: она читает текстовый файл с кодом
(обычно с расширением `.py`) и выполняет его строку за строкой. Код можно
писать в любом текстовом редакторе, а запускать — командой в терминале.

Для этой базы нужен **Python 3.12 или новее**. Более старые версии
(особенно Python 2) не подойдут: часть синтаксиса в примерах появилась
только в новых версиях.

## Установка

### Linux

Python 3 почти всегда уже установлен. Проверьте версию (как открыть
терминал — ниже):

```bash
python3 --version
```

Если версия ниже 3.12 или команда не найдена, установите Python через
менеджер пакетов дистрибутива:

```bash
sudo apt install python3        # Debian, Ubuntu
sudo dnf install python3        # Fedora
```

Если в репозиториях дистрибутива версия слишком старая, поставьте новую
через [pyenv](https://github.com/pyenv/pyenv) или из пакетов
[deadsnakes](https://launchpad.net/~deadsnakes/+archive/ubuntu/ppa)
(Ubuntu).

### macOS

Скачайте установщик с [python.org/downloads](https://www.python.org/downloads/)
и запустите его — или, если уже пользуетесь [Homebrew](https://brew.sh),
выполните `brew install python`. Проверка:

```bash
python3 --version
```

### Windows

Скачайте установщик с [python.org/downloads](https://www.python.org/downloads/).
На первом экране установщика **поставьте галочку «Add python.exe to
PATH»** — иначе терминал не найдёт команду `python`. Проверка:

```powershell
py --version
python --version
```

## Терминал и команда `cd`

Терминал — окно, где команды вводятся текстом:

- **Linux:** приложение «Терминал» (часто `Ctrl+Alt+T`).
- **macOS:** приложение «Терминал» (Terminal) — найдите через Spotlight
  (`Cmd+Пробел`, ввести «Terminal»).
- **Windows:** «PowerShell» или «Терминал Windows» из меню «Пуск».

Терминал всегда «находится» в какой-то папке — она называется текущей.
Перейти в другую папку можно командой `cd` (change directory):

```bash
cd my_projects/4_python_my_knowledgebase   # перейти в папку
cd ..                                      # подняться на уровень выше
pwd                                        # показать текущую папку (Linux/macOS)
ls                                         # список файлов (в PowerShell тоже работает)
```

Все команды запуска в README этой базы пишутся **относительно папки
темы**: сначала `cd` в папку темы, потом запуск.

## `python3`, `python` или `py` — какую команду использовать

> **Главное правило для этой базы.** В README и комментариях встречается
> и `python3`, и `python` — это одна и та же команда «запустить Python 3».
> Используйте ту, что работает у вас:
>
> - **Linux и macOS:** `python3`. Голая команда `python` там может
>   отсутствовать или (на старых системах) запускать устаревший Python 2.
> - **Windows:** `py` (лаунчер, ставится вместе с Python) или `python`.
>   Команды `python3` в Windows обычно нет или она открывает Microsoft
>   Store.
> - **Внутри активированного виртуального окружения (venv)** на любой
>   системе `python` уже указывает на нужную версию — там можно писать
>   просто `python`.
>
> Если в README написано `python файл.py`, а у вас Linux/macOS без venv —
> пишите `python3 файл.py`.

Проверить, что команда запускает именно Python 3.12+:

```bash
python3 --version     # должно быть Python 3.12.x или новее
```

## Запуск скрипта

Скрипт — это файл `.py`. Запуск: имя команды и путь к файлу.

```bash
cd 1_python/1_python_fundamentals/00_setup
python3 02_examples/01_hello.py
```

Ожидаемый вывод:

```text
Привет! Python работает.
Этот текст напечатан второй строкой скрипта.
5
```

`print(...)` — встроенная функция, которая печатает то, что передано в
скобках. Подробно о ней — в теме 1.3. Ошибка
`No such file or directory` / `can't open file` почти всегда значит, что
вы не в той папке: проверьте `pwd`/`ls` и путь к файлу.

## REPL — интерактивный режим

Если запустить `python3` без имени файла, откроется интерактивный режим
(REPL — read-eval-print loop). Приглашение `>>>` означает «жду команду»:
введите выражение, нажмите Enter — Python сразу покажет результат.

```text
$ python3
>>> 2 + 3
5
>>> print("привет")
привет
>>> exit()
```

Выйти: `exit()`, либо `Ctrl+D` (Linux/macOS), либо `Ctrl+Z` и Enter
(Windows). REPL удобен, чтобы быстро проверить одну строку; упражнения и
примеры запускаются как файлы.

## Редактор кода

Подойдёт любой редактор, который сохраняет простой текст. Два удобных
бесплатных варианта:

- [VS Code](https://code.visualstudio.com/) + расширение «Python» от
  Microsoft — подсветка, подсказки, запуск файла кнопкой.
- [PyCharm Community](https://www.jetbrains.com/pycharm/) — среда,
  сделанная специально для Python.

Не используйте Word или другие текстовые процессоры: они добавляют в файл
форматирование, и Python его не прочитает. Отступы делайте **пробелами**
(4 пробела на уровень) — оба редактора делают так по умолчанию для `.py`.
