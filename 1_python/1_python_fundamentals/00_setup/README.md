# Тема 1.0. Установка Python и первый запуск

Подготовительная тема перед первой строкой кода: установить Python,
открыть терминал, перейти в нужную папку и запустить скрипт.

## Зачем этот раздел

Все следующие темы предполагают, что вы умеете запустить файл командой
вида `python3 02_examples/01_user_profile.py` и понимаете, что делать,
если команда не сработала. Здесь это разобрано один раз для Linux, macOS
и Windows — включая частую путаницу между `python3`, `python` и `py`.
После темы у вас будет рабочий Python 3.12+, выбранный редактор и
запущенный первый скрипт.

**Уже знакомы с темой?** → [CHEATSHEET.md](../CHEATSHEET.md#10-установка-и-запуск) — раздел «1.0 Установка и запуск» общей шпаргалки основ.

## Что нужно знать заранее

Ничего — только умение пользоваться компьютером и устанавливать программы.

## Структура раздела

- **[01_theory/](./01_theory/)** — теория:
  - [01_install_and_run.md](./01_theory/01_install_and_run.md) — установка
    Python 3.12+ на Linux/macOS/Windows, терминал и `cd`, какую команду
    использовать (`python3`/`python`/`py`), запуск скрипта, REPL, выбор
    редактора, куда смотреть про виртуальные окружения.
- **[02_examples/](./02_examples/)** — пример:
  - [01_hello.py](./02_examples/01_hello.py) — первый скрипт из трёх
    `print()`, чтобы проверить, что всё работает.

Упражнений с самопроверкой в этой теме нет — проверка здесь одна: ваш
первый скрипт запустился и напечатал ожидаемый текст.

## Как проходить

1. Прочитайте теорию:
   [01_install_and_run.md](./01_theory/01_install_and_run.md), по ходу
   установите Python и редактор.
2. Откройте терминал, перейдите в эту папку и запустите пример:
   ```bash
   cd 1_python/1_python_fundamentals/00_setup
   python3 02_examples/01_hello.py
   ```
3. Откройте REPL (`python3` без аргументов), посчитайте `2 + 3` и выйдите
   через `exit()`.

## Когда двигаться дальше

Если `python3 --version` (или `py --version` на Windows) показывает 3.12
или новее, а `01_hello.py` печатает три строки — переходите к теме
[1.1. Переменные и типы данных](../01_variables_and_types/).
