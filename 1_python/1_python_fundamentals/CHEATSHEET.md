Теория: [01_install_and_run.md](./00_setup/01_theory/01_install_and_run.md)

| :--- | :--- |
| Версия Python (нужна 3.12+) | `python3 --version` (Windows: `py --version`) |

## 1.1 Переменные и типы

Теория: [01_variables_and_types.md](./01_variables_and_types/01_theory/01_variables_and_types.md)

| Тип | Литерал | Преобразование |
| :--- | :--- | :--- |
| `int` | `42`, `-7` (без ограничения размера) | `int("42")` → `42` |
| `float` | `3.14` | `float("3.5")` → `3.5` |
| `str` | `"hello"` | `str(42)` → `"42"` |
| `bool` | `True`, `False` (подвид `int`: `True + True == 2`) | `bool(0)` → `False` |
| `NoneType` | `None` — «значения нет» | — |

| Задача | Синтаксис |
| :--- | :--- |
| Присвоить несколько сразу | `x, y = 1, 2` |
| Обменять значения | `x, y = y, x` |
| Одно значение двум именам | `a = b = 0` |
| Тип значения / имя типа строкой | `type(42)` → `<class 'int'>` / `type(42).__name__` → `'int'` |

- Динамическая типизация: тип у значения, а не у имени (`age = 25`, потом `age = "25"` — допустимо).
- Имена — `snake_case`; `CamelCase` — для классов.
- ⚠️ `int("abc")` → `ValueError`, а не «пустое» значение.
- ⚠️ `"10" + "10"` → `"1010"` (склейка строк, а не сложение).

## 1.2 Операторы и выражения

Теория: [01_operators_and_expressions.md](./02_operators_and_expressions/01_theory/01_operators_and_expressions.md)

| Оператор | Пример | Результат |
| :--- | :--- | :--- |
| `/` деление (всегда `float`) | `10 / 2` | `5.0` |
| `//` целочисленное деление | `7 // 3` | `2` |
| `%` остаток | `7 % 3` | `1` |
| `**` степень | `7 ** 3` | `343` |
| `== != > < >= <=` | `5 >= 5` | `True` |
| `and` / `or` / `not` | `age >= 18 and age < 65` | `bool` |
| `+=`, `-=`, `*=` | `x += 1` | `x = x + 1` |
| f-строка | `f"{name}, тебе {age + 1}"` | выражения внутри `{}` |

- Приоритет: `**` → `* / // %` → `+ -` → сравнения → `not` → `and` → `or`. Сомневаетесь — ставьте скобки.
- Инвариант: `(a // b) * b + a % b == a`.
- ⚠️ `2 + 3 * 4 == 14`, а не `20`.

## 1.3 Ввод и вывод

Теория: [01_input_output.md](./03_input_output/01_theory/01_input_output.md)

| Задача | Синтаксис |
| :--- | :--- |
| Напечатать несколько значений через пробел | `print("Имя:", name)` |
| Свой разделитель | `print("a", "b", "c", sep="-")` → `a-b-c` |
| Без перевода строки | `print("Загрузка", end="...")` |
| Прочитать строку с подсказкой | `name = input("Как тебя зовут? ")` |
| Прочитать число | `age = int(input("Возраст: "))` |
| 2 знака после запятой | `f"{19.999:.2f}"` → `'20.00'` |
| Комментарий | `# объясняет «почему», а не «что»` |

- ⚠️ `input()` всегда возвращает `str`: `input() * 2` для ввода `5` даст `"55"`.
- ⚠️ `input(...) + 1` → `TypeError` — сначала `int(...)`.

## 1.4 Ветвления и циклы

Теория: [01_control_flow_basics.md](./04_control_flow_basics/01_theory/01_control_flow_basics.md)

```python
if age < 18:
    ...
elif age < 65:          # выполняется только первая подходящая ветка
    ...
else:
    ...

for fruit in ["яблоко", "груша"]:   # «для каждого элемента»
    ...
for i in range(2, 5):               # 2, 3, 4 — конец не включается
    ...
while count < 3:                    # пока условие истинно
    count += 1
```

| Задача | Синтаксис |
| :--- | :--- |
| Числа `0..n-1` | `range(n)` |
| Числа `a..b-1` | `range(a, b)` |
| Прервать цикл целиком | `break` |
| Перейти к следующей итерации | `continue` |
| Проверить «пусто ли» | `if items:` / `if not items:` |

- Falsy: `0`, `0.0`, `""`, `None`, `[]`, `{}`. Всё остальное — truthy.
- ⚠️ Смесь табов и пробелов → `IndentationError`.
- ⚠️ Забыли менять условие в `while` → бесконечный цикл.

## 1.5 Функции

Теория: [01_functions_basics.md](./05_functions_basics/01_theory/01_functions_basics.md)

```python
def apply_discount(price: float, discount_percent: float = 10) -> float:
    """Возвращает цену со скидкой."""
    return price - price * discount_percent / 100

apply_discount(200)                         # 180.0 — по умолчанию
apply_discount(discount_percent=50, price=200)  # 100.0 — именованные, порядок не важен
```

| Задача | Синтаксис |
| :--- | :--- |
| Вернуть значение | `return x` (функция сразу завершается) |
| Нет `return` | функция возвращает `None` |
| Параметр по умолчанию | `def greet(name, greeting="Привет")` — обязательные идут первыми |
| Docstring | строка `"""..."""` первой строкой тела; видна в `help(f)` |
| Аннотации типов | `x: int`, `-> str` — Python их **не проверяет**, проверяет `mypy`/редактор |

- ⚠️ Изменяемое значение по умолчанию (`def f(x=[])`) создаётся один раз и делится между вызовами — используйте `None` ([разбор в 2_basics](../2_basics/01_theory/03_mutability_and_identity.md)).

## 1.6 Исключения

Теория: [01_exceptions.md](./06_exceptions/01_theory/01_exceptions.md)

```python
try:
    number = int(text)
except ValueError as e:        # конкретный тип, а не голый except
    print(f"Ошибка: {e}")
else:
    print(number)              # только если ошибки не было
finally:
    print("готово")            # всегда
```

| Исключение | Когда | Пример |
| :--- | :--- | :--- |
| `ValueError` | тип верный, значение нет | `int("abc")` |
| `TypeError` | операция не для этого типа | `"5" + 5` |
| `ZeroDivisionError` | деление на ноль | `10 / 0` |
| `NameError` | имя не объявлено | `print(user_nmae)` |
| `KeyError` / `IndexError` | нет ключа / индекса | `d["x"]` / `lst[10]` |

| Задача | Синтаксис |
| :--- | :--- |
| Несколько типов — разная реакция | несколько блоков `except` подряд |
| Выбросить своё | `raise ValueError(f"Возраст < 0: {age}")` |
| Залогировать и пробросить дальше | `raise` без аргументов внутри `except` |
| Значение с кавычками в сообщении | `f"{text!r}"` |
| Спрашивать, пока ввод не верный | `while True:` + `try`/`except ... continue` + `break` |

- Traceback читается **снизу вверх**: последняя строка — тип и сообщение.
- ⚠️ Голый `except:` прячет баги (опечатка → `NameError` выглядит как «плохой ввод»).
- ⚠️ Код «при успехе» — в `else`, а не в `try`, чтобы не перехватить его ошибки.

## 1.7 Модули и import

Теория: [01_modules_and_imports.md](./07_modules_and_imports/01_theory/01_modules_and_imports.md)

| Задача | Синтаксис |
| :--- | :--- |
| Подключить модуль целиком | `import math` → `math.sqrt(16)` |
| Взять отдельные имена | `from math import sqrt, pi` |
| Псевдоним | `import random as rnd` |
| Из пакета | `from os import path` |
| Случайное целое `a..b` включительно | `random.randint(1, 6)` |
| Случайное `[0.0, 1.0)` | `random.random()` |
| Воспроизводимая случайность | `random.seed(42)` |
| Округлить до n знаков (без import) | `round(3.14159, 2)` → `3.14` |
| Код только при прямом запуске | `if __name__ == "__main__":` |

- При `import` файл выполняется целиком сверху вниз; `__name__` равно имени модуля, а не `"__main__"`.
- ⚠️ `ModuleNotFoundError` для сторонней библиотеки — она не установлена (`pip install` внутри venv).
- ⚠️ Длинный список `from x import ...` скрывает, откуда пришло имя.
