# Переменные и типы данных

Переменная — это имя, под которым в памяти хранится значение. В Python
переменную не нужно заранее объявлять с типом: тип определяется самим
значением, которое ей присвоили.

## Присваивание

Присваивание делает знак `=`. Слева — имя переменной, справа — значение.

```python
age = 25
name = "Alex"
is_admin = True
```

После `age = 25` имя `age` ссылается на объект-число `25`. Присвоить другое
значение той же переменной можно в любой момент — и тип при этом может
измениться:

```python
age = 25
age = "двадцать пять"  # это допустимо: тип не зафиксирован, переменная просто
                        # теперь ссылается на другой объект
```

Это называется **динамической типизацией**: тип принадлежит значению, а не
имени переменной. В отличие от языков со статической типизацией (Go, Java),
Python не проверяет на этапе компиляции, что в `age` всегда будет число.

Несколько переменных можно присвоить за один раз:

```python
x, y = 1, 2        # x == 1, y == 2
x, y = y, x         # обмен значениями без временной переменной
a = b = 0           # обе переменные указывают на одно и то же значение 0
```

## Имена переменных

Имя может содержать буквы, цифры и `_`, не может начинаться с цифры.
Соглашение Python (PEP 8) — `snake_case`: слова строчными буквами через
нижнее подчёркивание, например `user_name`, `total_count`. Имена,
начинающиеся с заглавной буквы (`UserName`), по соглашению означают классы,
а не обычные переменные — об этом подробнее в разделе про ООП.

## Базовые типы

| Тип | Пример | Что это |
|---|---|---|
| `int` | `42`, `-7` | целое число, без ограничения размера |
| `float` | `3.14`, `-0.5` | число с плавающей точкой |
| `str` | `"hello"` | строка текста |
| `bool` | `True`, `False` | логическое значение |
| `NoneType` | `None` | «значения нет», аналог null в других языках |

Узнать тип значения можно функцией `type()`:

```python
type(42)        # <class 'int'>
type(3.14)      # <class 'float'>
type("hello")   # <class 'str'>
type(True)      # <class 'bool'>
type(None)      # <class 'NoneType'>
```

Если нужно только **имя** типа строкой (без `<class '...'>`), допишите
`.__name__` после вызова: `type(42).__name__` даёт строку `"int"`, а
`type(None).__name__` — `"NoneType"`. Точка здесь значит «взять у
результата его свойство с таким именем»; двойные подчёркивания — просто
часть имени этого свойства. Подробнее о свойствах объектов — в разделе ООП,
а пока достаточно запомнить эту запись целиком:

```python
print(type(3.14).__name__)   # float
```

`bool` — технически подвид `int`: `True` равно `1`, `False` равно `0`. Это
видно, если сложить два булевых значения: `True + True` даёт `2`, не ошибку.

## Преобразование типов

Строку "42", введённую пользователем, нельзя напрямую складывать с числом —
нужно явно преобразовать тип:

```python
text = "42"
number = int(text)      # 42 (int)
back = str(number)      # "42" (str)
fraction = float("3.5") # 3.5 (float)
```

Если преобразование невозможно, Python поднимает ошибку, а не возвращает
«пустое» значение:

```python
int("abc")  # ValueError: invalid literal for int() with base 10: 'abc'
```

Это осознанное решение языка: лучше явная ошибка сразу, чем тихо испорченное
значение, которое всплывёт в непредсказуемом месте позже.

## Проверить понимание

Что выведет этот код и почему?

```python
value = "10"
result = value + value
print(result)
```

<details>
<summary>Разбор</summary>

Выведет `1010`, а не `20`. `value` — строка (`str`), а не число: оператор `+`
для строк означает конкатенацию (склеивание), а не сложение. Чтобы получить
`20`, сначала нужно преобразовать строку в число: `int(value) + int(value)`.

</details>
