# Тема 01. Переменные и типы данных

Этот раздел — самая первая тема для того, кто раньше не писал на Python:
как присвоить значение переменной, что такое динамическая типизация,
базовые типы (`int`, `float`, `str`, `bool`, `None`) и как преобразовывать
значения между типами.

## Структура раздела

- **[01_theory/](./01_theory/)** — теория:
  - [01_variables_and_types.md](./01_theory/01_variables_and_types.md) —
    присваивание `=`, динамическая типизация, имена переменных, базовые
    типы, `type()`, преобразование типов.
- **[02_examples/](./02_examples/)** — практические примеры:
  - [01_user_profile.py](./02_examples/01_user_profile.py) — переменные
    разных типов, преобразование строки в число, `bool` как подвид `int`.
- **[03_exercises/](./03_exercises/)** — задачи с самопроверкой `PASS`/`FAIL`:
  - `01_convert_and_sum` — преобразование строк в числа и сложение.
  - `02_type_name` — определение имени типа значения через `type()`.
- **[04_exercises_answers/](./04_exercises_answers/)** — эталонные решения.

## Как проходить тему

1. Прочитайте теорию:
   [01_variables_and_types.md](./01_theory/01_variables_and_types.md).
2. Запустите пример:
   ```bash
   python 02_examples/01_user_profile.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python 03_exercises/01_convert_and_sum.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.

Дальше: [операторы и выражения](../02_operators_and_expressions/).
