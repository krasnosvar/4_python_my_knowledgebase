# Тема 1.1. Переменные и типы данных

Первая тема про сам язык для того, кто раньше не писал на Python:
как присвоить значение переменной, что такое динамическая типизация,
базовые типы (`int`, `float`, `str`, `bool`, `None`) и как преобразовывать
значения между типами.

## Зачем этот раздел

Любая программа хранит и меняет данные: имя пользователя, цену товара,
флаг «оплачено». Эта тема учит давать значениям имена (переменные) и
понимать, какого они типа, — без этого нельзя ни сложить два числа,
введённых пользователем, ни понять сообщение об ошибке
`TypeError: can only concatenate str (not "int") to str`. После темы вы
сможете создать переменные разных типов, узнать тип значения и
преобразовать строку в число.

**Уже знакомы с темой?** → [CHEATSHEET.md](../CHEATSHEET.md#11-переменные-и-типы) — раздел «1.1 Переменные и типы» общей шпаргалки основ.

## Как проходить

1. Прочитайте теорию:
   [01_variables_and_types.md](./01_theory/01_variables_and_types.md).
2. Запустите пример:
   ```bash
   python3 02_examples/01_user_profile.py
   ```
3. Выполните задачи в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python3 03_exercises/01_convert_and_sum.py
   ```
4. Сверьтесь с эталонными ответами в `04_exercises_answers/`.
