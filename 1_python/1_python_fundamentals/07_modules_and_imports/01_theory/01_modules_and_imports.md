# Модули и import

Пока весь наш код помещался в один файл. Но готовые решения — квадратный
корень, случайные числа, работа с датами — писать заново не нужно: они
уже лежат в других файлах, и их можно **подключить**. Механизм для этого
называется `import`.

## Что такое модуль

**Модуль** — это просто файл `.py`. Всё, что в нём объявлено (переменные,
функции), можно использовать из другого файла. Вместе с Python
поставляется **стандартная библиотека** — сотни готовых модулей, например
`math` (математика) и `random` (случайные числа).

## import x

```python
import math

print(math.sqrt(16))   # 4.0 - квадратный корень
print(math.pi)         # 3.141592653589793
print(math.floor(3.7)) # 3 - округление вниз
```

`import math` подключает модуль целиком, а к его содержимому обращаются
через точку: `math.sqrt`, `math.pi`. Имя модуля перед точкой сразу
показывает, откуда взялась функция.

## from x import y

Если из модуля нужны одна-две вещи, их можно импортировать по имени и
использовать без префикса:

```python
from math import sqrt, pi

print(sqrt(25))   # 5.0 - без "math."
print(pi)
```

Удобно, но с осторожностью: при длинном списке таких импортов по коду
становится непонятно, где объявлена функция `sqrt` — в этом файле или
где-то ещё.

## import x as y

Модулю можно дать короткое имя (псевдоним):

```python
import random as rnd

print(rnd.randint(1, 6))   # случайное целое от 1 до 6 включительно
```

Так часто пишут для модулей с длинными названиями — в следующих разделах
и в чужом коде ты встретишь, например, `import datetime as dt`.

## Модуль random

```python
import random

print(random.randint(1, 6))   # случайное целое от 1 до 6 включительно
print(random.random())        # случайное дробное от 0.0 до 1.0 (не включая 1.0)

random.seed(42)               # «зафиксировать» случайность
print(random.randint(1, 100)) # после seed(42) каждый запуск даст одно и то же
```

`random.seed(...)` делает последовательность «случайных» чисел
воспроизводимой — это полезно в тестах и примерах, где нужен
одинаковый результат при каждом запуске.

Мелочь, которая пригодится в упражнениях: встроенная функция
`round(x, n)` (без import — она всегда доступна, как `print`) округляет
число до `n` знаков после запятой: `round(3.14159, 2)` → `3.14`.

## `if __name__ == "__main__":` — зачем это в каждом упражнении

У каждого модуля есть встроенная переменная `__name__`:

- если файл **запустили напрямую** (`python my_file.py`), в нём
  `__name__ == "__main__"`;
- если файл **импортировали** из другого (`import my_file`), в нём
  `__name__ == "my_file"` (имя модуля).

Поэтому код под этой проверкой выполняется только при прямом запуске:

```python
def area(width, height):
    return width * height


if __name__ == "__main__":
    print(area(3, 4))   # напечатается при python this_file.py,
                        # но НЕ при import this_file из другого файла
```

Именно так устроены все упражнения в этом репозитории: функция, которую
ты пишешь, объявлена вверху, а самопроверка `_self_check()` запускается
только под `if __name__ == "__main__":`. Благодаря этому функцию можно
импортировать в другой файл (например, в тест) — и самопроверка не
запустится сама собой.

## Пакеты

Когда модулей становится много, их складывают в папку — она называется
**пакетом** (package). Импорт из пакета пишется через точку:
`from os import path`, `import xml.etree.ElementTree`. Для начала
достаточно понимать: точка в импорте — это «папка → файл → объект внутри».

## Сторонние библиотеки и pip

Кроме стандартной библиотеки, есть сотни тысяч модулей от других
разработчиков (например, `requests` для HTTP-запросов, `pytest` для
тестов). Их нет в Python «из коробки» — их устанавливают командой
`pip install requests`, обычно внутри **виртуального окружения**
(отдельной папки с библиотеками для конкретного проекта). Как это
делать правильно — в
[other/01_environments_and_packaging](../../../../other/01_environments_and_packaging/).
Если пример где-то в репозитории падает с `ModuleNotFoundError` — значит,
нужная библиотека не установлена.

## Проверить понимание

Файл `geometry.py`:

```python
def square(x):
    return x * x

print("Привет из geometry")

if __name__ == "__main__":
    print(square(5))
```

Что будет напечатано, если в другом файле написать `import geometry`?

<details>
<summary>Разбор</summary>

Напечатается только `Привет из geometry`. При импорте Python выполняет
весь файл сверху вниз, поэтому `print` на верхнем уровне сработает. А
`__name__` в этот момент равно `"geometry"`, а не `"__main__"`, поэтому
блок под `if __name__ == "__main__":` пропускается и `25` не
напечатается. Отсюда правило: код, который не должен выполняться при
импорте, кладут под эту проверку.

</details>
