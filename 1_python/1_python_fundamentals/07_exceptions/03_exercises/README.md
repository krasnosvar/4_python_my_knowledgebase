# Упражнения: исключения

Каждое упражнение — самостоятельный скрипт с `# TODO:` пометками. Реализуйте
недостающую часть и запустите файл напрямую:

```bash
python3 03_exercises/01_safe_int.py
```

Пока `TODO` не реализован, скрипт упадёт с `NotImplementedError` — это тоже
исключение, и его traceback полезно прочитать снизу вверх. Неверный ответ
остановит самопроверку с `AssertionError` и пояснением в последней строке
traceback. После правильной реализации самопроверка печатает `PASS` по
каждой проверке и итог вида `2/2 проверок пройдено`.

Эталонные решения — в [04_exercises_answers/](../04_exercises_answers/), с
теми же именами файлов.
