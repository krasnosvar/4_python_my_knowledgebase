# Тема 1. Абсолютные основы Python (Python Fundamentals)

Здесь собраны базовые конструкции языка Python, упорядоченные по
возрастанию сложности для изучения с нуля — для тех, кто раньше не писал
код на Python вообще. Если синтаксис уже знаком, можно сразу перейти к
[2_basics](../2_basics/), где разбираются более тонкие идиомы и ловушки
языка.

## Зачем этот раздел

Это вход в базу для тех, кто ещё не писал код на Python: от установки
интерпретатора до функций, исключений и модулей. Все остальные темы
(`2_basics` и дальше) предполагают, что этот синтаксис уже читается
свободно. После раздела вы сможете написать и запустить небольшой скрипт с
вводом, ветвлениями, циклами и функциями, прочитать traceback и подключить
модуль стандартной библиотеки.

**Уже знакомы с темой?** → [CHEATSHEET.md](./CHEATSHEET.md) — все подтемы 1.0–1.7 на паре экранов: синтаксис, команды, частые ошибки.

## Что нужно знать заранее

Ничего, кроме умения устанавливать программы. Установка Python и работа с
терминалом разобраны в теме [1.0](./00_setup/).

## Как устроен файл упражнения

Каждое упражнение — это файл `.py` с функцией, которую нужно дописать, и
самопроверкой внизу. В темах 1.1–1.4 там встречаются `def`, `return`,
`raise NotImplementedError`, `if __name__ == "__main__":` и списки `[...]`
— до того, как вы их прошли. Это нормально:

- **редактируйте только строку под `TODO`** — строку с
  `raise NotImplementedError(...)` внутри функции: замените её на
  `return <ваше выражение>`; значение после `return` — ответ функции;
- **не трогайте** строку `def ...`, функцию `_self_check()` и блок
  `if __name__ == "__main__":` — это проверка вашего ответа;
- `def`/`return` и аннотации типов объяснены в теме
  [1.5](./05_functions_basics/), `raise` — в [1.6](./06_exceptions/),
  `if __name__ == "__main__":` — в [1.7](./07_modules_and_imports/).

Подробнее, с разбором на примере — в `03_exercises/README.md` тем 1.1–1.4.

## Карта изучения (Learning Path)

Каждая папка содержит теорию, примеры и практические упражнения для
самостоятельного прохождения (в `00_setup` — только теория и пример):

0. **[00_setup](./00_setup/)** — установка Python 3.12+, терминал и `cd`,
   `python3`/`python`/`py`, запуск скрипта, REPL, выбор редактора.
1. **[01_variables_and_types](./01_variables_and_types/)** — присваивание,
   динамическая типизация, базовые типы (`int`/`float`/`str`/`bool`/`None`),
   `type()`, преобразование типов.
2. **[02_operators_and_expressions](./02_operators_and_expressions/)** —
   арифметика, сравнения, логические операторы, приоритет операторов,
   f-строки, составное присваивание.
3. **[03_input_output](./03_input_output/)** — `print()` и его параметры,
   `input()`, комментарии, форматирование чисел.
4. **[04_control_flow_basics](./04_control_flow_basics/)** — отступы как
   границы блока кода, `if`/`elif`/`else`, truthy/falsy, `for`, `range()`,
   `while`, `break`/`continue`.
5. **[05_functions_basics](./05_functions_basics/)** — `def`, параметры и
   аргументы, `return`, значения по умолчанию, docstring, аннотации типов.
6. **[06_exceptions](./06_exceptions/)** — traceback, `try`/`except`,
   `else`/`finally`, `raise`, проверка ввода в цикле.
7. **[07_modules_and_imports](./07_modules_and_imports/)** — `import`,
   `from ... import`, `math`/`random`, `if __name__ == "__main__":`, пакеты
   и `pip`.

## Как проходить

1. Переходите в соответствующую папку по порядку от `00` до `07`.
2. Читайте теорию в `01_theory/`.
3. Запускайте примеры из `02_examples/` через `python3` (на Windows —
   `py`; см. [тему 1.0](./00_setup/01_theory/01_install_and_run.md)).
4. Выполняйте упражнения из `03_exercises/`, доводя самопроверку до `PASS`.
5. Сверяйте свои решения с эталонными ответами в `04_exercises_answers/`.

## Когда двигаться дальше

Когда можешь написать небольшую функцию с `if`/`for` внутри, перехватить
`ValueError` от `int(input())`, подключить модуль через `import` и
объяснить, зачем нужен `if __name__ == "__main__":` — двигайся к
[2_basics](../2_basics/): это уже следующий уровень, он предполагает
свободное владение синтаксисом из этого раздела.
