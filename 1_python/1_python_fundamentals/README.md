# Тема 1. Основы Python (Python Fundamentals)

Здесь собраны базовые конструкции и составные типы языка Python,
упорядоченные по возрастанию сложности для изучения с нуля: от запуска
первого скрипта, переменных, условий и циклов до коллекций (`list`,
`tuple`, `set`, `dict`), функций, исключений и модулей.

## Зачем этот раздел

Это точка входа в базу: все остальные разделы предполагают, что синтаксис
Python и базовые коллекции читаются свободно. После этого раздела вы
сможете написать и запустить скрипт с вводом, ветвлениями, циклами,
списками, словарями и функциями, не попадётесь в ловушку общих ссылок и
изменяемых параметров по умолчанию, сможете прочитать traceback и
подключить модуль стандартной библиотеки.

**Уже знакомы с темой?** → [CHEATSHEET.md](./CHEATSHEET.md) — все подтемы
1.0–1.8 на нескольких экранах: синтаксис, коллекции, частые ошибки.

Ничего, кроме умения устанавливать программы. Установка Python и работа с

## Как устроен файл упражнения

Каждое упражнение — это файл `.py` с функцией, которую нужно дописать, и
самопроверкой внизу. В темах 1.1–1.5 там встречаются `def`, `return`,
`raise NotImplementedError` и `if __name__ == "__main__":` — до того, как
вы их прошли. Это нормально:

- **редактируйте только строку под `TODO`** — строку с
  `raise NotImplementedError(...)` внутри функции: замените её на
  `return <ваше выражение>`; значение после `return` — ответ функции;
- **не трогайте** строку `def ...`, функцию `_self_check()` и блок
  `if __name__ == "__main__":` — это проверка вашего ответа;
- `def`/`return` и аннотации типов объяснены в теме
  [1.6](./06_functions_basics/), `raise` — в [1.7](./07_exceptions/),
  `if __name__ == "__main__":` — в [1.8](./08_modules_and_imports/).

Подробнее, с разбором на примере — в `03_exercises/README.md` тем 1.1–1.5.

## Карта изучения (Learning Path)

Каждая папка содержит теорию, примеры и практические упражнения для
самостоятельного прохождения (в `00_setup` — только теория и пример):

0. **[00_setup](./00_setup/)** — установка Python 3.12+, терминал и `cd`,
   `python3`/`python`/`py`, запуск скрипта, REPL, выбор редактора.
1. **[01_variables_and_types](./01_variables_and_types/)** — присваивание,
   динамическая типизация, базовые типы (`int`/`float`/`str`/`bool`/`None`)
   и их особенности, `type()`, преобразование типов.
2. **[02_operators_and_expressions](./02_operators_and_expressions/)** —
   арифметика, сравнения, логические операторы, приоритет операторов,
   f-строки, составное присваивание.
3. **[03_input_output](./03_input_output/)** — `print()` и его параметры,
   `input()`, комментарии, форматирование чисел.
4. **[04_control_flow](./04_control_flow/)** — отступы как границы блока
   кода, `if`/`elif`/`else`, truthy/falsy, `for`, `range()`, `while`,
   `break`/`continue`, `for...else`, `match`/`case`.
5. **[05_collections](./05_collections/)** — `list`, `tuple`, `set`,
   `dict`, индексация и срезы, изменяемость и общие ссылки, `is` против
   `==`, копирование, `list`/`dict`/`set` comprehensions.
6. **[06_functions_basics](./06_functions_basics/)** — `def`, параметры и
   аргументы, `return`, значения по умолчанию и ловушка `def f(x=[])`,
   docstring, аннотации типов.
7. **[07_exceptions](./07_exceptions/)** — traceback, `try`/`except`,
   `else`/`finally`, `raise`, проверка ввода в цикле.
8. **[08_modules_and_imports](./08_modules_and_imports/)** — `import`,
   `from ... import`, `math`/`random`/`decimal`/`copy`,
   `if __name__ == "__main__":`, пакеты и `pip`.

## Как проходить

1. Переходите в соответствующую папку по порядку от `00` до `08`.
2. Читайте теорию в `01_theory/`.
3. Запускайте примеры из `02_examples/` через `python3` (на Windows —
   `py`; см. [тему 1.0](./00_setup/01_theory/01_install_and_run.md)).
4. Выполняйте упражнения из `03_exercises/`, доводя самопроверку до `PASS`.
5. Сверяйте свои решения с эталонными ответами в `04_exercises_answers/`.

## Когда двигаться дальше

Когда вы можете написать функцию со списками, словарями и условиями
внутри, объяснить, почему `def f(items=[])` — ошибка, перехватить
`ValueError` через `try`/`except`, подключить модуль через `import` и
объяснить, зачем нужен `if __name__ == "__main__":` — переходите к
[2_functions_and_decorators](../2_functions_and_decorators/).
