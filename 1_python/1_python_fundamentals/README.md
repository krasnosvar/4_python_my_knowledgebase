# Раздел 1. Абсолютные основы Python (Python Fundamentals)

Здесь собраны базовые конструкции языка Python, упорядоченные по
возрастанию сложности для изучения с нуля — для тех, кто раньше не писал
код на Python вообще. Если синтаксис уже знаком, можно сразу перейти к
[2_basics](../2_basics/), где разбираются более тонкие идиомы и ловушки
языка.

## Карта изучения (Learning Path)

Каждая папка содержит теорию, примеры и практические упражнения для
самостоятельного прохождения:

1. **[01_variables_and_types](./01_variables_and_types/)** — присваивание,
   динамическая типизация, базовые типы (`int`/`float`/`str`/`bool`/`None`),
   `type()`, преобразование типов.
2. **[02_operators_and_expressions](./02_operators_and_expressions/)** —
   арифметика, сравнения, логические операторы, приоритет операторов,
   f-строки, составное присваивание.
3. **[03_input_output](./03_input_output/)** — `print()` и его параметры,
   `input()`, комментарии, форматирование чисел.
4. **[04_control_flow_basics](./04_control_flow_basics/)** — отступы как
   границы блока кода, `if`/`elif`/`else`, truthy/falsy, `for`, `range()`,
   `while`, `break`/`continue`.
5. **[05_functions_basics](./05_functions_basics/)** — `def`, параметры и
   аргументы, `return`, значения по умолчанию, docstring, аннотации типов.
6. **[06_exceptions](./06_exceptions/)** — traceback, `try`/`except`,
   `else`/`finally`, `raise`, проверка ввода в цикле.
7. **[07_modules_and_imports](./07_modules_and_imports/)** — `import`,
   `from ... import`, `math`/`random`, `if __name__ == "__main__":`, пакеты
   и `pip`.

## Как проходить темы

1. Переходите в соответствующую папку по порядку от `01` до `07`.
2. Читайте теорию в `01_theory/`.
3. Запускайте примеры из `02_examples/` через `python`.
4. Выполняйте упражнения из `03_exercises/`, доводя самопроверку до `PASS`.
5. Сверяйте свои решения с эталонными ответами в `04_exercises_answers/`.

## Когда двигаться дальше

Когда можешь написать небольшую функцию с `if`/`for` внутри, перехватить
`ValueError` от `int(input())`, подключить модуль через `import` и
объяснить, зачем нужен `if __name__ == "__main__":` — двигайся к
[2_basics](../2_basics/): это уже следующий уровень, он предполагает
свободное владение синтаксисом из этого раздела.
