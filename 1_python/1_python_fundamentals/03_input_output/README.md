# Тема 1.3. Ввод и вывод

`print()` и его параметры `sep`/`end`, `input()` и то, что он всегда
возвращает строку, комментарии `#`, форматирование чисел в f-строках.

## Зачем этот раздел

Программа полезна, когда общается с человеком: спрашивает данные и
показывает результат. Эта тема учит управлять выводом через `print()` и
получать ввод через `input()` — и объясняет главную ловушку новичка:
`input()` всегда возвращает строку, даже если ввели число. После темы вы
сможете написать маленький интерактивный скрипт и красиво
отформатировать числа в выводе.

**Уже знакомы с темой?** → [CHEATSHEET.md](../CHEATSHEET.md#13-ввод-и-вывод) — раздел «1.3 Ввод и вывод» общей шпаргалки основ.

## Как проходить

1. Прочитайте теорию:
   [01_input_output.md](./01_theory/01_input_output.md).
2. Запустите пример (он спросит ваше имя и возраст):
   ```bash
   python3 02_examples/01_greeting_cli.py
   ```
3. Выполните задачу в `03_exercises/`, запуская файл для самопроверки:
   ```bash
   python3 03_exercises/01_build_greeting.py
   ```
4. Сверьтесь с эталонным ответом в `04_exercises_answers/`.
