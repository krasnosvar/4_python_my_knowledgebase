# Ввод и вывод

Программа должна как-то получать данные и показывать результат. В консольном
Python-скрипте за это отвечают две встроенные функции: `print()` для вывода
и `input()` для ввода.

## print()

`print()` выводит в консоль переданные значения, разделяя их пробелом по
умолчанию и добавляя перевод строки в конце:

```python
print("Привет")           # Привет
print("Имя:", "Alex")     # Имя: Alex
print(1, 2, 3)             # 1 2 3
```

Поведение можно настроить через именованные параметры `sep` (разделитель
между значениями) и `end` (что вывести вместо перевода строки):

```python
print("a", "b", "c", sep="-")        # a-b-c
print("Загрузка", end="...")          # не переходит на новую строку
print("готово")                       # допечатается на ту же строку:
                                       # Загрузка...готово
```

## input()

`input()` выводит подсказку (необязательную) и ждёт, пока пользователь
введёт текст и нажмёт Enter. Результат **всегда строка**, даже если
пользователь ввёл число:

```python
name = input("Как тебя зовут? ")   # name - всегда str
age_text = input("Сколько тебе лет? ")
age = int(age_text)                 # преобразование нужно сделать явно
```

Если пропустить преобразование и попытаться использовать `age_text` как
число (например, прибавить 1), Python поднимет ошибку `TypeError`, потому
что `+` между `str` и `int` не определён напрямую.

## Комментарии

`#` начинает комментарий — всё после него на строке Python игнорирует.
Комментарии объясняют **почему** код написан именно так, а не повторяют
то, что и так видно из самого кода:

```python
# Плохо: просто повторяет код словами
x = x + 1  # прибавить 1 к x

# Лучше: объясняет, зачем именно
x = x + 1  # компенсируем нулевую индексацию для показа пользователю
```

## Форматирование чисел в выводе

f-строки (раздел 2) поддерживают спецификаторы формата после `:` внутри
`{}` — например, чтобы ограничить число знаков после запятой:

```python
price = 19.999
print(f"Цена: {price:.2f}")   # Цена: 20.00 (округление до 2 знаков)
```

## Проверить понимание

Пользователь вводит `input("Введите число: ")` и получает `"5"`. Что
выведет следующий код и почему именно так, а не иначе?

```python
value = input("Введите число: ")
print(value * 2)
```

<details>
<summary>Разбор</summary>

Если пользователь ввёл `5`, выведет `55`, а не `10`. `input()` всегда
возвращает строку, а оператор `*` между строкой и числом означает
«повторить строку указанное число раз», а не умножение чисел. Чтобы
получить `10`, нужно сначала преобразовать: `int(value) * 2`.

</details>
