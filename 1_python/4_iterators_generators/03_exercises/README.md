# Упражнения: iterators & generators

Каждый файл — самостоятельная задача с `# TODO:` внутри и встроенной самопроверкой.

Запуск задачи:

```bash
python 03_exercises/01_custom_iterator_class.py
```

Пока `TODO` не реализован, скрипт бросит `NotImplementedError`. После реализации — самопроверка выведет `PASS` или `FAIL` с пояснением.

Эталонные решения: `04_exercises_answers/<то же имя файла>`.
