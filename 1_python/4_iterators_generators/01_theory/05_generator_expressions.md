# Генераторные выражения

Генераторное выражение — компактный способ создать генератор без `def`/`yield`, синтаксически похожий на comprehension, но с круглыми скобками:

```python
squares_list = [x * x for x in range(10)]   # list comprehension — список сразу в памяти
squares_gen  = (x * x for x in range(10))   # generator expression — ленивый генератор
```

## Отличия от list comprehension

| | `[x for x in ...]` | `(x for x in ...)` |
|---|---|---|
| Тип результата | `list` | генератор |
| Когда вычисляются элементы | сразу, при создании | лениво, по одному, при `next()` |
| Память | O(N) | O(1) |
| Повторный проход | да, сколько угодно | нет, одноразовый |
| `len()`, индексация | да | нет |

Оба варианта используют одну и ту же грамматику comprehension (`for`, вложенные `for`, `if`-фильтры), различается только тип результата и момент вычисления.

## Одноразовость

Как и любой генератор, генераторное выражение исчерпывается после одного полного прохода:

```python
gen = (x for x in range(3))
print(list(gen))   # [0, 1, 2]
print(list(gen))   # [] — уже пусто
```

## Синтаксический сахар: без лишних скобок

Если генераторное выражение передаётся как **единственный** аргумент функции, дополнительные скобки можно опустить:

```python
total = sum(x * x for x in range(10))        # так, без двойных скобок
total = sum((x * x for x in range(10)))       # эквивалентно, но избыточно

# а если аргументов несколько - скобки обязательны, иначе неоднозначность парсинга:
result = sum((x for x in range(10)), start=100)
```

Это работает для любой функции, принимающей iterable первым/единственным позиционным аргументом: `sum`, `max`, `min`, `any`, `all`, `sorted`, `"".join(...)` и т.д. На практике это самый частый способ использования генераторных выражений — как разовый аргумент агрегирующей функции, без промежуточного списка.
