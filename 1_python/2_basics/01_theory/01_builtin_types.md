# Базовые встроенные типы: int, float, bool, None

Эти типы ты уже встречал в fundamentals. Здесь — их поведение, которое
удивляет на практике.

## `int` — целые числа без переполнения

Во многих языках у целого числа фиксированный размер (например, 64 бита),
и слишком большое число «переполняется» — превращается в мусор. В Python
`int` не переполняется: если число не помещается, Python просто выделяет
под него больше памяти.

```python
huge = 2 ** 1000          # обычный int, никакого переполнения
print(len(str(huge)))     # 302 — столько цифр в этом числе
```

Это удобно, но не бесплатно: операции над очень большими числами медленнее,
чем над обычными.

## `float` — неточная дробь

`float` хранит дробное число в двоичном виде с ограниченной точностью
(стандарт IEEE 754 — так же, как почти во всех языках). Многие «круглые»
десятичные дроби в двоичном виде записываются только приблизительно:

```python
0.1 + 0.2 == 0.3   # False!
0.1 + 0.2          # 0.30000000000000004
```

Причина — `0.1` и `0.2` нельзя записать в двоичной системе точно (как `1/3`
нельзя точно записать десятичной дробью). Практические следствия:

- Не сравнивайте `float` через `==`. Сравнивайте с допуском: модуль `math`
  из стандартной библиотеки содержит функцию `math.isclose(a, b)` — она
  отвечает «равны ли числа с точностью до крошечной погрешности».
- Для денег используйте целые (храните копейки, а не рубли) или тип
  `Decimal` из модуля `decimal` — он считает в десятичной системе точно.

```python
import math                     # подключить модуль (см. fundamentals 07)
math.isclose(0.1 + 0.2, 0.3)    # True

from decimal import Decimal
Decimal("0.1") + Decimal("0.2") == Decimal("0.3")   # True
```

## `bool` — на самом деле число

`True` и `False` в Python — это особые версии чисел `1` и `0`. Встроенная
функция `isinstance(значение, тип)` отвечает, относится ли значение к типу:

```python
isinstance(True, int)   # True — bool является разновидностью int
True == 1               # True
True + True             # 2 (!) — арифметика работает
```

Отсюда практичный приём: чтобы посчитать, сколько элементов подходит под
условие, можно складывать результаты сравнений — каждый `True` даст `+1`:

```python
scores = [40, 75, 90, 55]
passed = 0
for score in scores:
    passed += score >= 60   # True прибавит 1, False прибавит 0
print(passed)               # 2
```

## `None` — «значения нет»

`None` — единственный объект своего типа, означает «здесь ничего нет»:

- значение по умолчанию для «нет значения» (в отличие от `0`, `""`,
  `False`, которые являются полноценными значениями);
- результат функции, которая ничего не вернула явно (без `return` или с
  пустым `return`).

Проверять на `None` принято через `is None`, а не `== None`. Почему именно
`is` — разобрано в
[03_mutability_and_identity.md](./03_mutability_and_identity.md#is-против-).

```python
def find_user(user_id: int) -> str | None:
    if user_id == 42:
        return "Анна"
    return None

user = find_user(7)
if user is None:
    print("Пользователь не найден")
```

`-> str | None` — аннотация: «вернёт строку или `None`».
