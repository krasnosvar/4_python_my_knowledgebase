# Два новых управляющих конструкции: `for...else` и `match`

`if`/`elif`/`else`, `for`, `while`, `break`/`continue` ты уже знаешь из
[1_python_fundamentals](../../1_python_fundamentals/04_control_flow_basics/01_theory/01_control_flow_basics.md)
— здесь они не разбираются заново. Единственное, что стоит добавить к уже
известному: раз в Python нет классического `switch` (до версии 3.10),
множественный выбор традиционно строился через `if/elif/.../else` или через
словарь функций (`dispatch table`) — а с 3.10 для этого появился `match`
(см. ниже). Подробнее про то, что стоит за `for` на уровне протокола
итератора, — в модуле [5_iterators_generators](../../5_iterators_generators/).

Ниже — две конструкции, которых в `1_python_fundamentals` не было.

## `for...else` / `while...else` — редкая, но полезная конструкция

Блок `else` у цикла выполняется, если цикл завершился **без `break`**. Это
удобно для паттерна «искали что-то — не нашли»:

```python
def find_first_negative(numbers):
    for n in numbers:
        if n < 0:
            print("Найдено отрицательное:", n)
            break
    else:
        print("Отрицательных чисел нет")
```

Без `else` пришлось бы заводить отдельный флаг (`found = False`, ..., `if not
found: ...`). `else` у цикла существует именно для того, чтобы избавиться от
этого шаблонного кода — хотя из-за неочевидного названия («else» относится к
«if break не сработал», а не к самому циклу) конструкция считается
недооценённой и редко используемой на практике.

## `match` / `case` — структурное сопоставление с образцом (с Python 3.10)

`match` — не просто `switch`: он умеет распаковывать структуру объекта
(последовательности, словари, атрибуты объектов), а не только сравнивать
значение.

```python
def handle_command(command):
    match command:
        case ("move", x, y):
            print(f"Двигаемся в ({x}, {y})")
        case ("say", str(message)):
            print(f"Сообщение: {message}")
        case {"action": "quit"}:
            print("Выход")
        case [first, *rest] if len(rest) > 0:
            print(f"Первый: {first}, остальные: {rest}")
        case _:
            print("Неизвестная команда")
```

Ключевые элементы:

- **паттерны** могут распаковывать кортежи/списки (`(a, b)`), словари
  (`{"key": value}`, лишние ключи игнорируются), классы (`Point(x=0, y=0)`);
- **guard** — дополнительное условие `if ...` после паттерна, паттерн
  подходит, только если guard истинен;
- `_` — wildcard, совпадает с чем угодно, используется как «default» (аналог
  `else`), но также может встречаться внутри паттерна для игнорирования части
  значения (например, `case (x, _, z)`).

`match` уместен там, где раньше был бы длинный `if isinstance(...)`/цепочка
`elif`, разбирающая структуру данных (парсинг команд, обработка сообщений
разных форматов, разбор AST). Для простого сравнения одного значения с
несколькими константами `if/elif` часто остаётся не менее читаемым выбором.
