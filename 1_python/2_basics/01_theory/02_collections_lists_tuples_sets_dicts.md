# Списки, кортежи, множества, словари

Коллекция — значение, которое хранит внутри несколько других значений. В
Python четыре основные встроенные коллекции. Сначала — как ими
пользоваться, потом — чем они отличаются и когда какую выбирать.

## Синтаксис за 2 минуты

### `list` — список

Упорядоченный набор значений, который можно менять.

```python
fruits = ["яблоко", "груша", "слива"]   # создать список
empty = []                              # пустой список

fruits[0]       # "яблоко" — элемент по индексу, счёт с 0
fruits[-1]      # "слива"  — отрицательный индекс считает с конца
fruits[0:2]     # ["яблоко", "груша"] — срез: с 0 до 2, не включая 2
fruits[:]       # копия всего списка

len(fruits)     # 3 — количество элементов
fruits.append("киви")   # добавить в конец
fruits[1] = "манго"     # заменить элемент
"груша" in fruits       # True/False — есть ли элемент в списке

for fruit in fruits:    # перебор, как в fundamentals
    print(fruit)
```

`fruits.append(...)` — вызов **метода**: функции, которая «принадлежит»
значению и работает с ним. Пишется через точку.

### `tuple` — кортеж

Как список, но **изменить нельзя**. Пишется в круглых скобках:

```python
point = (10, 20)
point[0]          # 10 — индексы и срезы работают так же
# point[0] = 5    # ошибка: кортеж менять нельзя

x, y = point      # распаковка: x = 10, y = 20
a, b = 1, 2       # то же самое: справа неявно создаётся кортеж (1, 2)
```

### `set` — множество

Набор **уникальных** значений без порядка:

```python
tags = {"python", "backend", "python"}   # дубль исчезнет
print(tags)        # {'python', 'backend'} — порядок не гарантирован
tags.add("sql")    # добавить элемент
"sql" in tags      # True
empty = set()      # пустое множество (не {} — это пустой словарь!)
```

### `dict` — словарь

Пары «ключ → значение». Ищем значение не по номеру, а по ключу:

```python
ages = {"Анна": 30, "Борис": 25}
ages["Анна"]            # 30 — значение по ключу
ages["Вера"] = 41       # добавить или заменить пару
"Борис" in ages         # True — проверяет КЛЮЧИ
ages.get("Глеб")        # None — нет такого ключа, но без ошибки
ages.get("Глеб", 0)     # 0 — значение по умолчанию
# ages["Глеб"]          # ошибка KeyError: такого ключа нет

ages.keys()     # все ключи
ages.values()   # все значения
for name, age in ages.items():   # пары (ключ, значение) + распаковка
    print(name, age)
```

### Мини-словарь терминов

Дальше в этом и следующих файлах встречаются слова:

- **O(1)** («за константу») — время операции не зависит от размера
  коллекции: что 10 элементов, что миллион — одинаково быстро.
- **O(n)** («линейно») — время растёт вместе с размером: в 10 раз больше
  элементов — примерно в 10 раз дольше. Подробно — в
  [9_algorithms_dsa](../../9_algorithms_dsa/01_theory/01_big_o_notation.md).
- **Изменяемый** (mutable) — объект можно менять «на месте» (`list`,
  `dict`, `set`); **неизменяемый** — нельзя (`tuple`, `str`, `int`).
  Подробно — в [03_mutability_and_identity.md](./03_mutability_and_identity.md).
- **Хешируемый** — значение, которое можно использовать как ключ словаря
  или элемент множества. Подробно — в
  [04_hashability_and_performance.md](./04_hashability_and_performance.md).
- **Хеш-таблица** — способ хранения, при котором по значению сразу
  вычисляется «адрес», где оно лежит; поэтому поиск не требует перебора.
  Так устроены `set` и `dict`.

## `list` — изменяемый список

Список — это ряд пронумерованных ячеек. Отсюда скорость операций:

- взять элемент по индексу `lst[i]` — O(1): номер ячейки известен сразу;
- добавить в конец `append()` — в среднем O(1);
- вставить или удалить в начале/середине (`insert(0, x)`, `del lst[0]`) —
  O(n): все следующие элементы приходится сдвигать;
- проверка `x in lst` — O(n): перебор с начала до первого совпадения.

```python
lst = [1, 2, 3]
lst.append(4)      # быстро
lst.insert(0, 0)   # медленно на больших списках — сдвигает всё
```

<details>
<summary>Для любопытных: как список устроен в памяти</summary>

В CPython список хранит не сами значения, а ссылки на объекты, лежащие в
памяти отдельно («массив указателей»). При `append` Python выделяет место
с запасом (over-allocation), поэтому большинство добавлений не требуют
перевыделять память — отсюда «в среднем O(1)».

</details>

### Ловушка: `[список] * n`

```python
row = [0] * 3
grid = [row] * 3          # ловушка: все три строки — ОДИН И ТОТ ЖЕ список!
grid[0][0] = 1
print(grid)                # [[1, 0, 0], [1, 0, 0], [1, 0, 0]] — изменилось везде

grid_ok = []
for _ in range(3):
    grid_ok.append([0] * 3)   # правильно: каждая строка — новый список
```

`[row] * 3` кладёт в новый список три ссылки на **один и тот же** `row`, а
не три копии. Почему так происходит — в
[03_mutability_and_identity.md](./03_mutability_and_identity.md).
`_` в `for _ in range(3)` — принятое имя для переменной, которая не нужна.

## `tuple` — неизменяемая последовательность

Кортеж нельзя изменить после создания. Благодаря этому:

- кортеж может быть ключом словаря или элементом множества — **если все
  его элементы тоже неизменяемые**;
- он уместен для «записи» фиксированной формы (координата `(x, y)`, пара
  `(host, port)`), а список — для набора однотипных элементов переменной
  длины.

```python
point = (10, 20)
cache = {(10, 20): "значение в этой точке"}   # OK, кортеж годится в ключ

bad = ([1, 2], "label")
# {bad: "..."}   # ошибка TypeError — внутри кортежа список
```

## `set` — множество

Хранит уникальные значения без гарантии порядка. Устроено как
хеш-таблица, поэтому `x in s` — O(1) в среднем. Главные применения —
быстрая проверка «было ли такое» и удаление дублей:

```python
incoming_ids = [3, 1, 3, 2, 1]
seen = set()
unique_ids = []
for event_id in incoming_ids:
    if event_id not in seen:      # O(1) в среднем
        seen.add(event_id)
        unique_ids.append(event_id)
print(unique_ids)                  # [3, 1, 2] — порядок первых появлений
```

## `dict` — словарь

Тоже хеш-таблица: `d[key]` — O(1) в среднем. С Python 3.7 словарь
**гарантированно** помнит порядок, в котором добавлялись ключи: `for k in d`
перебирает их в этом порядке.

### Ловушка: повторяющиеся ключи

Если при создании словаря ключ встречается дважды, остаётся **последнее**
значение — предыдущее молча теряется:

```python
d = {"a": 1, "a": 2}
print(d)   # {'a': 2}

pairs = [("x", 1), ("x", 2), ("y", 3)]
result = dict(pairs)   # dict() строит словарь из списка пар
print(result)          # {'x': 2, 'y': 3}
```

## Когда что использовать

| Нужно | Используйте |
|---|---|
| Изменяемая последовательность произвольной длины | `list` |
| Неизменяемая «запись» фиксированной формы, возможный ключ словаря | `tuple` |
| Быстрая проверка «есть ли», уникальность, порядок не важен | `set` |
| Быстрый поиск значения по ключу | `dict` |
