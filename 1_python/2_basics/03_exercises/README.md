# Упражнения: типы и коллекции изнутри

Каждое упражнение — самостоятельный скрипт с `# TODO:` пометками. Реализуйте недостающую часть и запустите файл напрямую:

```bash
python 03_exercises/01_mutable_default_arg.py
```

Пока `TODO` не реализован, скрипт упадёт с `NotImplementedError`. Если ответ неверный, самопроверка остановится на первой несовпавшей проверке с `AssertionError` — пояснение в последней строке traceback. После правильной реализации самопроверка печатает `PASS` по каждой проверке и итог вида `3/3 проверок пройдено`.

Эталонные решения — в [04_exercises_answers/](../04_exercises_answers/), с теми же именами файлов.
