# Веб-фреймворки и фоновые задачи

Раздел про то, как Python-приложение превращается в веб-сервис и как
из него вынести тяжёлую/ненадёжную работу за пределы HTTP-запроса:
FastAPI, Django, Celery — и как выбирать между ними под конкретный
проект.

## Формат тем

Темы `1_fastapi`, `2_django`, `3_celery` устроены по одному шаблону:

- `01_theory/` — краткая теория без лишней воды, с акцентом на
  почему/компромиссы, а не только на API;
- `02_examples/` — рабочий, запускаемый пример;
- `03_exercises/` — упражнения от простого к сложному с `TODO`-заглушками
  (стартовое состояние задачи);
- `04_exercises_answers/` — эталонные решения для самопроверки.

`4_stack_comparison` — исключение: это раздел про выбор архитектуры, а
не про конкретный инструмент, поэтому в нём только `01_theory/`.

## Разделы

1. [1_fastapi](./1_fastapi/) — async-first фреймворк: основы HTTP
   (методы, статус-коды, запрос/ответ) и первое приложение, когда
   `async def` реально даёт выгоду, Pydantic (валидация, модели,
   вложенные схемы, особенности v2), Dependency Injection,
   Alembic-миграции поверх SQLAlchemy.
2. [2_django](./2_django/) — batteries-included фреймворк: структура
   проекта и модели, ленивые QuerySet'ы,
   `select_related`/`prefetch_related` и решение N+1 на уровне ORM,
   сигналы.
3. [3_celery](./3_celery/) — вынесение тяжёлой работы за пределы
   запроса: архитектура (broker/worker/result backend), задачи и
   очереди, retry/countdown, периодические задачи (`celery beat`),
   когда Celery оправдан, а когда достаточно `asyncio`-фона.
4. [4_stack_comparison](./4_stack_comparison/) — FastAPI vs Django,
   где в этой картине Celery, критерии выбора стека по типу проекта.

## Как проходить

1. Начать с [1_fastapi](./1_fastapi/) и [2_django](./2_django/) —
   изучить оба фреймворка независимо, прогоняя примеры и упражнения.
2. Перейти к [3_celery](./3_celery/), чтобы понять, как фоновые задачи
   встраиваются поверх любого из двух фреймворков.
3. Закрыть раздел [4_stack_comparison](./4_stack_comparison/) — свести
   всё в критерии выбора: какой стек брать под маленький сервис, монолит
   с админкой, высоконагруженный async API.

Упражнения специально содержат `TODO`: это стартовое состояние задачи,
готовые решения лежат рядом в `04_exercises_answers/`.
