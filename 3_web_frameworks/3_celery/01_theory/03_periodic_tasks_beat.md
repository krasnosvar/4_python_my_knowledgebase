# Периодические задачи: Celery Beat

## Что такое beat

`celery beat` — это отдельный процесс-планировщик, аналог cron внутри мира
Celery. Он ничего сам не выполняет: единственная его работа — по расписанию
класть задачи в очередь брокера, точно так же, как это делает `.delay()` из
кода приложения. Выполняют задачи, как обычно, worker-процессы.

Это значит, что beat и worker — два разных процесса, которые нужно запускать
отдельно:

```bash
celery -A app.celery_app worker --loglevel=info
celery -A app.celery_app beat --loglevel=info
```

Если beat не запущен — расписание просто не сработает, даже если worker
исправно работает: некому класть задачи в очередь по таймеру.

## Расписание в конфиге

```python
# celery_app.py
from celery.schedules import crontab

app.conf.beat_schedule = {
    "cleanup-every-night": {
        "task": "app.tasks.cleanup_expired_sessions",
        "schedule": crontab(hour=3, minute=0),  # каждый день в 03:00
    },
    "send-daily-report": {
        "task": "app.tasks.send_report",
        "schedule": crontab(hour=9, minute=0),
        "args": (1,),  # аргументы для задачи, если нужны
    },
    "heartbeat-every-30s": {
        "task": "app.tasks.heartbeat",
        "schedule": 30.0,  # можно просто интервал в секундах
    },
}
```

`schedule` принимает либо число секунд (простой интервал), либо
`crontab(...)` для расписаний в стиле cron (конкретное время, дни недели
и т.д.).

## Типичные кейсы

- ночная очистка устаревших данных (просроченные сессии, временные файлы,
  старые записи в логах);
- регулярная рассылка отчётов (ежедневных, еженедельных дайджестов);
- периодическая синхронизация с внешними системами;
- health-check / heartbeat задачи для мониторинга.

## Важная деталь

Beat-расписание описывает *когда положить задачу в очередь*, а не когда она
гарантированно выполнится. Если все worker-ы заняты или недоступны, задача
подождёт в очереди — это то же самое поведение, что и у обычных задач,
поставленных через `.delay()`. Beat не заменяет worker и не следит за тем,
выполнилась ли предыдущая задача, прежде чем поставить следующую по
расписанию.
