# Упражнение 2: периодическая задача через celery beat

## Задание

В `celery_app.py` есть задача `cleanup_tmp_files` (в `tasks.py`), которая
"чистит" временные файлы (в учебных целях — просто логирует факт запуска).
Настройте `beat_schedule` так, чтобы:

1. `cleanup_tmp_files` запускалась каждые 15 секунд (для удобства проверки —
   в реальном проекте это было бы что-то вроде "раз в сутки ночью");
2. отдельно, через `crontab`, задача `daily_digest` запускалась бы каждый
   день в 09:00 (просто настройте расписание — реального времени ждать для
   проверки не нужно, важно, что конфигурация корректна).

Отметка `# TODO` в `celery_app.py` показывает, где добавить `beat_schedule`.

## Как проверить

1. Поднимите Redis (можно переиспользовать `docker compose up -d redis` из
   `02_examples`).

2. Запустите worker и beat как два отдельных процесса (из директории
   `02_periodic_task`):

   ```bash
   pip install celery redis
   celery -A celery_app worker --loglevel=info
   ```

   и в другом терминале:

   ```bash
   celery -A celery_app beat --loglevel=info
   ```

3. Наблюдайте в логе worker-а, что каждые ~15 секунд там появляется запись о
   выполнении `cleanup_tmp_files` — это подтверждает, что beat действительно
   кладёт задачу в очередь по расписанию, а worker её забирает и исполняет.

4. Для `daily_digest` реального часа ждать не нужно: достаточно убедиться,
   что `celery beat` запустился без ошибок конфигурации (в логе beat при
   старте печатается список зарегистрированных периодических задач с их
   расписанием) — значит, `crontab(hour=9, minute=0)` разобран корректно.
