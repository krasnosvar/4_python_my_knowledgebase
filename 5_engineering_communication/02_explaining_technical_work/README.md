# Тема 02. Объяснение технической работы разной аудитории

## Зачем этот раздел

Умение объяснить сложную вещь — отдельный навык, не совпадающий с умением её сделать. Тема учит готовить объяснение на 30–60 секунд и подбирать уровень абстракции под слушателя: нетехнического стейкхолдера, коллегу из другой команды, новичка. После неё вы сможете рассказать о своей работе так, чтобы решения принимались с нужным контекстом.

**Уже знакомы с темой?** → [CHEATSHEET.md](../CHEATSHEET.md#02-объяснение-технической-работы) — раздел этой темы в общей шпаргалке.

## Что нужно знать заранее

Технических предварительных знаний не нужно — тему можно проходить в любой
момент. Полезно держать в голове одну-две свои реальные рабочие или учебные
ситуации, чтобы примерять материал на них.

## Файлы темы

- [01_theory/README.md](./01_theory/README.md) — теория: техника «объяснение за одну минуту», адаптация уровня абстракции, жаргон без потери точности, структура «что / зачем / что это даёт».
- [02_practice/README.md](./02_practice/README.md) — практика: чек-лист и
  сценарии для самостоятельной отработки.

## Как проходить

1. Прочитайте теорию в [01_theory/](./01_theory/README.md).
2. Пройдите чек-лист из [02_practice/](./02_practice/README.md) на своей
   реальной ситуации.
3. Разберите сценарии: сначала письменно сформулируйте свой ответ, потом
   сверьтесь с подсказкой по подходу.

## Когда двигаться дальше

Когда для двух-трёх своих значимых задач у вас есть готовые минутные объяснения и вы можете пересказать каждое для разных аудиторий — переходите к [03_professional_dialogue](../03_professional_dialogue/).
