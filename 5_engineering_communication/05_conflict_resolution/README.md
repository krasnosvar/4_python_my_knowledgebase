# Тема 05. Конструктивное общение и работа с конфликтами

## Зачем этот раздел

Конфликты в команде неизбежны; задача — чтобы они разрешались по существу и не разрушали рабочие отношения. Тема учит отличать конфликт по существу от конфликта отношений, использовать основы ненасильственного общения и эскалировать без токсичности. После неё вы сможете высказать несогласие так, чтобы разговор сместился к «что делаем дальше».

**Уже знакомы с темой?** → [CHEATSHEET.md](../CHEATSHEET.md#05-конфликты) — раздел этой темы в общей шпаргалке.

## Что нужно знать заранее

Технических предварительных знаний не нужно — тему можно проходить в любой
момент. Полезно держать в голове одну-две свои реальные рабочие или учебные
ситуации, чтобы примерять материал на них.

## Файлы темы

- [01_theory/README.md](./01_theory/README.md) — теория: конфликт по существу vs конфликт отношений, основы ненасильственного общения (NVC), работа с конфликтом в команде, эскалация без токсичности.
- [02_practice/README.md](./02_practice/README.md) — практика: чек-лист и
  сценарии для самостоятельной отработки.

## Как проходить

1. Прочитайте теорию в [01_theory/](./01_theory/README.md).
2. Пройдите чек-лист из [02_practice/](./02_practice/README.md) на своей
   реальной ситуации.
3. Разберите сценарии: сначала письменно сформулируйте свой ответ, потом
   сверьтесь с подсказкой по подходу.

## Когда двигаться дальше

Когда вы можете переформулировать резкое замечание в структуру «наблюдение → чувство → потребность → просьба» и чек-лист из `02_practice/` проходит без исправлений — переходите к [06_structured_self_presentation](../06_structured_self_presentation/).
