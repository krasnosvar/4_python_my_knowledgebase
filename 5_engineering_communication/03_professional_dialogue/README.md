# Тема 03. Профессиональный диалог под давлением

## Зачем этот раздел

Ревью кода, разбор инцидента, спорное решение — в таких разговорах легко уйти в оборону или потерять уверенность. Тема учит отвечать по существу, признавать ошибки конструктивно и задавать уточняющие вопросы. После неё вы сможете держать неудобный разговор конструктивным и продвигающим дело.

**Уже знакомы с темой?** → [CHEATSHEET.md](../CHEATSHEET.md#03-диалог-под-давлением) — раздел этой темы в общей шпаргалке.

## Что нужно знать заранее

Технических предварительных знаний не нужно — тему можно проходить в любой
момент. Полезно держать в голове одну-две свои реальные рабочие или учебные
ситуации, чтобы примерять материал на них.

## Файлы темы

- [01_theory/README.md](./01_theory/README.md) — теория: ответы по существу без оправданий, конструктивное признание ошибок, уточняющие вопросы вместо поспешного ответа, уверенность без перехода в защиту.
- [02_practice/README.md](./02_practice/README.md) — практика: чек-лист и
  сценарии для самостоятельной отработки.

## Как проходить

1. Прочитайте теорию в [01_theory/](./01_theory/README.md).
2. Пройдите чек-лист из [02_practice/](./02_practice/README.md) на своей
   реальной ситуации.
3. Разберите сценарии: сначала письменно сформулируйте свой ответ, потом
   сверьтесь с подсказкой по подходу.

## Когда двигаться дальше

Когда в сценариях из `02_practice/` ваши письменные ответы начинаются с фактов и заканчиваются следующим шагом, а не с защиты себя, — переходите к [04_negotiation_basics](../04_negotiation_basics/).
