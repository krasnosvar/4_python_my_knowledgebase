# Решения

Полные, рабочие решения ко всем заданиям из `../03_exercises/README.md`.
Имена файлов совпадают с заготовками из `03_exercises/`, чтобы было легко
сверить свой вариант с решением построчно.

- `01_add_index.sql`, `02_explain_analyze.sql`,
  `03_fix_full_scan.sql` -- решения заданий 01–03 (индексы, EXPLAIN
  ANALYZE), с комментариями, объясняющими план выполнения и почему
  выбранное исправление работает.
- `04_transfer.py` -- перевод денег в одной транзакции с корректным
  rollback (задание 04).
- `05_n_plus_one.py` -- диагностика и исправление проблемы N+1 через
  `selectinload` (задание 05).
- `06_locking.py` -- pessimistic (`SELECT ... FOR UPDATE`) и
  optimistic (столбец `version`) блокировки для конкурентного списания
  товара со склада (задание 06, опциональное).

Стенд для проверки -- тот же, что и для заданий: `docker-compose.yml` и
`schema.sql` из `../02_examples/`.
