# 📚 Раздел 0. Инструменты и workflow (Tooling & Workflow)

Прежде чем переходить к языку — минимальный набор инструментов, без
которого не получится нормально работать в реальной команде: система
контроля версий и контейнеризация. Это не про Python как язык, а про то,
как код живёт, версионируется и запускается.

## 🧭 Карта изучения (Learning Path)

1. **[01_git_essentials](./01_git_essentials/)** — базовый workflow Git
   (`init`/`add`/`commit`/`push`/`pull`), ветвление и слияние, разрешение
   конфликтов, commit hygiene и безопасная отмена изменений
   (`restore`/`reset`/`revert`/`amend`).
2. **[02_docker_basics](./02_docker_basics/)** — образы vs контейнеры,
   `Dockerfile`, `docker-compose` для локальной разработки, volumes и
   сети, multi-stage builds.

## 🛠 Как проходить темы

1. Переходите в соответствующую папку по порядку от `01` до `02`.
2. Читайте теорию в `01_theory/`.
3. Разбирайте примеры из `02_examples/` — для Git это аннотированные
   bash-скрипты (`bash 02_examples/....sh`), для Docker — рабочий
   Dockerfile/compose, который можно собрать и запустить.
4. Выполняйте упражнения из `03_exercises/`, доводя `bash check.sh` до
   статуса `PASS` по всем пунктам.
5. Сверяйте свои решения с эталонными ответами в `04_exercises_answers/`.

## Зачем это в самом начале

Дальше по курсу примеры и упражнения всё чаще будут предполагать, что вы
умеете закоммитить изменения атомарным коммитом, разобраться с конфликтом
при слиянии веток и поднять локальное окружение (приложение + база данных)
одной командой `docker compose up`. Раздел [other](../other/) дополняет это
темами про виртуальные окружения, упаковку пакетов и статический анализ —
туда можно возвращаться по мере необходимости, не обязательно проходить его
подряд перед основным курсом.
