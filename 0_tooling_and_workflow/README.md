# Раздел 0. Инструменты и рабочий процесс (Tooling & Workflow)

## Зачем этот раздел

Минимальный набор инструментов, без которого не получится нормально
работать в реальной команде: система контроля версий и контейнеризация.
Это не про Python как язык, а про то, как код живёт, версионируется и
запускается. После раздела вы сможете вести историю своего кода в Git
(коммиты, ветки, конфликты, безопасная отмена) и поднимать приложение
с зависимостями через Docker и `docker compose`.

## Что нужно знать заранее

- **Git** — ничего, кроме умения открыть терминал. Если терминал пока
  незнаком, сначала пройдите урок
  [00_setup](../1_python/1_python_fundamentals/00_setup/) (установка Python,
  терминал, `cd`), затем возвращайтесь сюда.
- **Docker** — желательно уже пройти [1_python](../1_python/): приложения
  в упражнениях используют классы, `with`, `try`, сокеты и HTTP. Их код
  можно воспринимать как «чёрный ящик», но с базой языка будет спокойнее.

## Карта изучения (Learning Path)

1. **[01_git_essentials](./01_git_essentials/)** — базовый workflow Git
   (`init`/`add`/`commit`/`push`/`pull`), ветвление и слияние, разрешение
   конфликтов, commit hygiene и безопасная отмена изменений
   (`restore`/`reset`/`revert`/`amend`).
2. **[02_docker_basics](./02_docker_basics/)** — образы vs контейнеры,
   `Dockerfile`, `docker-compose` для локальной разработки, volumes и
   сети, multi-stage builds.

## Когда что проходить

- **Git — с самого начала.** Он пригодится уже на первых упражнениях
  [1_python](../1_python/): сохранять решения коммитами и откатывать
  неудачные попытки.
- **Docker можно отложить** до раздела
  [2_data_and_messaging](../2_data_and_messaging/): там PostgreSQL, Redis,
  Kafka и RabbitMQ поднимаются через `docker compose up`. Весь
  [1_python](../1_python/) проходится без Docker — достаточно установленного
  Python.

Раздел [other](../other/) дополняет это темами про виртуальные окружения,
упаковку пакетов и статический анализ — туда можно возвращаться по мере
необходимости.

## Как проходить

1. Переходите в соответствующую папку: `01` — сразу, `02` — перед
   [2_data_and_messaging](../2_data_and_messaging/).
2. Читайте теорию в `01_theory/`.
3. Разбирайте примеры из `02_examples/`:
   - **Git** — пошаговые разборы в `.md` (команда → вывод → объяснение):
     повторяйте команды руками в своём терминале и сверяйте вывод;
   - **Docker** — рабочий Dockerfile/compose, который можно собрать и
     запустить.
4. Выполняйте упражнения из `03_exercises/`:
   - **Git** — каждое упражнение (`NN_name.md`) состоит из разделов
     «Подготовка», «Задание» и «Проверь себя»; задание считается
     выполненным, когда команды из «Проверь себя» дают ожидаемый вывод;
   - **Docker** — доводите `bash check.sh` до статуса `PASS` по всем
     пунктам.
5. Сверяйте свои решения с эталонными ответами в `04_exercises_answers/`.
   Для Git есть ещё краткая шпаргалка
   [CHEATSHEET.md](./01_git_essentials/CHEATSHEET.md).

## Когда двигаться дальше

- После Git: когда умеете сделать атомарный коммит, создать ветку, слить
  её и разрешить конфликт — переходите к [1_python](../1_python/).
- После Docker: когда можете собрать образ по своему `Dockerfile` и поднять
  приложение с зависимостью через `docker compose up` — переходите к
  [2_data_and_messaging](../2_data_and_messaging/).
