# Упражнение 3. docker-compose с сервисом кэша

## Стартовое состояние

`Dockerfile` и `app/main.py` уже готовы и менять их не нужно. Приложение —
HTTP-сервер на `8080`:

- `GET /` — просто отвечает текстом.
- `GET /health` — пытается установить TCP-соединение с кэшем по адресу
  `CACHE_HOST:CACHE_PORT` (переменные окружения, по умолчанию `cache:6379`)
  и возвращает `200`, если удалось, `503` — если нет.

`docker-compose.yml` в этой папке пока не существует — ваша задача написать
его с нуля.

## Подсказки

- Внутри сети compose сервисы видят друг друга **по имени сервиса**, а не по
  `localhost`. Это и есть то, что должно заставить `/health` вернуть успех.
- Если тестируете руками и получаете `503` сразу после `up` — Redis мог ещё
  не успеть подняться; подождите пару секунд или добавьте `healthcheck`.
