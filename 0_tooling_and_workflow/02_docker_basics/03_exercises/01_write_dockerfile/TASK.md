# Упражнение 1. Написать Dockerfile с нуля

## Стартовое состояние

В папке `app/` лежит готовое Python-приложение (`main.py`) — простой
HTTP-сервер на стандартной библиотеке, слушающий порт `8080` и отвечающий
`hello from exercise app` на любой GET-запрос. Внешних зависимостей нет —
`requirements.txt` не нужен.

`Dockerfile` в этой папке пока не существует — ваша задача написать его.

## TODO

- [ ] Создать `Dockerfile` рядом с этим файлом (не внутри `app/`).
- [ ] Базовый образ — `python:3.12-slim`.
- [ ] Скопировать `app/main.py` внутрь образа.
- [ ] Указать `EXPOSE 8080`.
- [ ] `CMD` должен запускать `main.py` в **exec-форме** (списком, не строкой).
- [ ] Собрать образ и убедиться, что контейнер запускается и отвечает:
      ```bash
      docker build -t exercise-01 .
      docker run --rm -d -p 8080:8080 --name exercise-01 exercise-01
      curl http://localhost:8080/
      docker stop exercise-01
      ```

## Проверка

```bash
bash check.sh
```

`check.sh` сам соберёт образ по вашему `Dockerfile`, запустит контейнер,
проверит ответ на `http://localhost:8080/` и подчистит за собой
образ/контейнер.
