# Упражнения: docker_basics

Каждое упражнение — самостоятельная папка с уже готовым Python-кодом
приложения и `check.sh`, который реально собирает образ (и, где нужно,
поднимает `docker compose`) и проверяет результат. Требуется установленный
и запущенный Docker (`docker compose` — как плагин, без дефиса).

```bash
cd 01_write_dockerfile      # или любое другое
# ... выполняете TODO из TASK.md ...
bash check.sh
```

## Список упражнений

1. `01_write_dockerfile` — написать Dockerfile с нуля для готового
   stdlib-приложения.
2. `02_fix_broken_dockerfile` — найти и исправить ошибки в существующем
   Dockerfile (несоответствие имени файла и порта).
3. `03_compose_with_cache` — написать `docker-compose.yml` с сервисом
   приложения и сервисом кэша (Redis), связав их через сеть compose.

Эталонные решения — в `../04_exercises_answers/`, вместе с `solve.sh`,
который прогоняет весь сценарий от старта до `check.sh` одной командой.

`check.sh` в каждом упражнении подчищает за собой созданные образы,
контейнеры и volume'ы — можно запускать многократно.
