# Упражнения: git_essentials

Каждое упражнение — один `.md`-файл из трёх частей:

1. **Подготовка** — команды, которые создают стартовое состояние. Наберите
   их в терминале по порядку (или скопируйте блок целиком).
2. **Задание** — что нужно сделать. Команды здесь не даны — подберите их
   сами по теории и примерам.
3. **Проверь себя** — команды Git, которые нужно выполнить после решения,
   и вывод, который должен получиться. Хеши коммитов у вас будут другими,
   остальное должно совпадать.

Все упражнения выполняются в отдельной папке `~/git-practice/exNN`, вне
этого репозитория. Захотите начать заново — удалите папку
(`rm -rf ~/git-practice/exNN`) и повторите подготовку.

Перед первым упражнением выполните первичную настройку Git (имя и email) —
см. [01_basic_workflow.md → Установка и первая настройка](../01_theory/01_basic_workflow.md#установка-и-первая-настройка).

Команды подготовки рассчитаны на bash или zsh: терминал Linux/macOS или
Git Bash на Windows.
