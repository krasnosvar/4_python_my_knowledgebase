# Упражнения: git_essentials

В отличие от Go-упражнений, здесь нечего компилировать — вместо `go run` у
каждого упражнения есть пара скриптов:

- `setup.sh` — создаёт стартовое состояние в `./sandbox` (иногда это ещё не
  git-репозиторий, иногда — репозиторий с определённой историей коммитов);
- `check.sh` — после того как вы выполнили задание руками внутри `sandbox/`,
  проверяет результат и печатает `PASS`/`FAIL` по каждому пункту.

Порядок работы с любым упражнением:

```bash
cd 01_first_commit_and_gitignore   # или любое другое
bash setup.sh
cd sandbox
# ... выполняете TODO из TASK.md прямо здесь, руками, в git ...
cd ..
bash check.sh
```

`setup.sh` можно перезапускать сколько угодно раз — `sandbox/` каждый раз
пересоздаётся с нуля. Все git-команды в скриптах используют **локальный**
`user.name`/`user.email` внутри `sandbox/` и не трогают ваши глобальные
настройки git.

## Список упражнений

1. `01_first_commit_and_gitignore` — init, .gitignore, первый атомарный коммит.
2. `02_branch_and_merge` — создание ветки и fast-forward merge.
3. `03_resolve_merge_conflict` — разрешение реального конфликта слияния.
4. `04_amend_commit_safely` — безопасное исправление последнего локального коммита.
5. `05_restore_reset_revert` — restore для файлов, revert для уже опубликованной истории.

Эталонные решения — в `../04_exercises_answers/`, там же лежит `solve.sh`,
который прогоняет `setup.sh` → решение → `check.sh` одной командой.
