# Упражнение 1. Первый коммит и .gitignore

## Стартовое состояние

```bash
bash setup.sh
cd sandbox
```

Внутри `sandbox/` лежит папка с файлами Python-проекта, которая **ещё не
является git-репозиторием**:

- `app.py` — исходник, должен попасть в репозиторий;
- `secret.log` — лог-файл, в репозиторий попадать не должен;
- `__pycache__/app.cpython-312.pyc` — байткод-мусор, в репозиторий попадать
  не должен.

## Подсказки

- `.gitignore` не действует на уже отслеживаемые файлы — но в этом
  упражнении файлы ещё ни разу не коммитились, так что это не проблема.
- Формат `.gitignore` — по одному паттерну на строку, каталоги обычно
  оканчиваются на `/`.
