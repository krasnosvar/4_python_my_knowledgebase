# Упражнение 4. Безопасный amend последнего коммита

## Стартовое состояние

```bash
bash setup.sh
cd sandbox
```

Последний коммит называется `fix bug` — бесполезное сообщение, не
объясняющее, что и почему изменилось. Кроме того, в рабочей папке остался
файл `parser_test_notes.py`, который по смыслу должен был войти в тот же
коммит, но его забыли добавить.

Этот коммит существует **только локально** и никуда не запушен — значит,
его безопасно переписывать.

## Подсказки

- `git commit --amend` без `-m` откроет редактор с текущим сообщением для
  правки; с `git commit --amend -m "..."` можно задать сообщение напрямую.
- Если бы этот коммит уже был запушен и виден коллегам — amend делать не
  стоило бы: пришлось бы использовать `git revert` (см. упражнение 5) или
  явно предупреждать команду о force-push.
