## Стартовое состояние

```bash
bash setup.sh
cd sandbox
```

Есть ветка `main`, где `MAX_CONNECTIONS` увеличен до 50, и ветка
`feature/prod-settings`, где независимо от этого `DEBUG` выключен (`False`).
Обе ветки менялись относительно одного и того же файла `settings.py`.
